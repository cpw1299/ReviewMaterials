# UniApp 复习资料应用开发任务文档

## 0. 总原则

按 MVP 顺序执行。每个任务完成后都应能独立验证。

推荐 Codex CLI 按任务逐项执行，不要一次生成整个项目后再修。

## Phase 1：工程初始化

### TASK-001 初始化 UniApp

**目标**：创建 Vue 3 + TypeScript UniApp 工程。

**要求**：
- Vite；
- TypeScript；
- 基础 pages.json；
- H5 至少可启动。

**验收**：

```bash
npm install
npm run dev:h5
```

首页正常显示。

### TASK-002 建立目录和类型

创建：

```text
src/components
src/composables
src/stores
src/types
src/static/materials
```

实现 material.ts 类型。

**验收**：类型检查通过。

## Phase 2：资料数据管线

### TASK-003 实现 DOCX 转换器

实现：

```text
scripts/materials/convert_docx.py
```

要求：

- 读取段落；
- 识别标题；
- 读取表格；
- 提取图片；
- 保持顺序；
- 输出 Block；
- 支持 material id。

**验收**：当前机械制图 DOCX 能生成 JSON。

### TASK-004 实现语义识别

识别：

- 章节；
- 题号；
- 选项；
- 答案；
- 解析；
- 题型。

不能识别时保留为 Block。

**验收**：生成结果中存在可用 section/question。

### TASK-005 实现校验器

实现：

```text
scripts/materials/validate_materials.py
```

检查引用、ID、图片、题型、答案和 index。

**验收**：正常资料 exit code 0，故意损坏数据能报 ERROR。

### TASK-006 生成第一份静态资料

生成：

```text
src/static/materials/index.json
src/static/materials/mechanical-drawing-basic.json
src/static/materials/assets/...
```

**验收**：不依赖网络即可访问。

## Phase 3：数据加载

### TASK-007 实现 Material Loader

提供：

```ts
loadMaterialIndex()
loadMaterial(id)
```

要求统一错误处理和缓存。

### TASK-008 实现学习状态

实现 `study` store/composable：

- 当前章节；
- 已复习章节；
- 已做题目；
- 收藏；
- 最近位置。

Storage key：

```text
review:state:{materialId}
```

## Phase 4：页面

### TASK-009 首页

实现资料列表。

验收：显示机械制图资料及统计信息。

### TASK-010 资料详情

实现章节目录和继续学习。

验收：点击章节可进入阅读页。

### TASK-011 阅读页

实现：

- heading；
- paragraph；
- image；
- table；
- list；
- 上一节/下一节；
- 标记已复习。

验收：能够完整阅读样例资料。

### TASK-012 练习列表

显示题目列表和完成状态。

### TASK-013 单题练习

支持：

- 单选；
- 多选；
- 判断；
- 提交；
- 正误；
- 答案；
- 解析。

填空/简答先展示参考答案。

### TASK-014 搜索

搜索标题、正文、题干、选项、标签。

点击结果跳转到对应内容。

### TASK-015 收藏

支持题目收藏/取消收藏和收藏列表。

### TASK-016 设置

至少提供：

- 清除学习进度；
- 清除收藏；
- 关于。

## Phase 5：体验和质量

### TASK-017 空状态与错误状态

覆盖：

- 没有资料；
- JSON 加载失败；
- 搜索无结果；
- 没有收藏；
- 图片加载失败。

### TASK-018 移动端体验

检查：

- 点击区域；
- 长文本；
- 图片宽度；
- 横向表格；
- 刘海屏安全区；
- 页面滚动。

### TASK-019 性能

确认：

- 首页不加载全部资料；
- 资料点击后才加载 JSON；
- 不重复解析；
- 长列表不卡顿。

### TASK-020 离线验收

关闭网络后完成：

1. 打开 App；
2. 查看资料；
3. 阅读章节；
4. 看图片；
5. 搜索；
6. 做题；
7. 收藏；
8. 重启后恢复进度。

## Codex CLI 工作约束

1. 先阅读本文件、设计文档、开发文档；
2. 先检查现有仓库，不覆盖已有资料；
3. 每次只完成一个 TASK 或一个紧密相关的小组；
4. 修改后运行对应测试；
5. 不擅自增加后端；
6. 不擅自把 DOCX 解析搬进 App；
7. 不引入大型依赖解决简单问题；
8. 数据格式变更必须同步更新类型和校验器；
9. 新资料必须经过 validate；
10. 完成后给出修改文件、测试命令和结果。

## 最终 MVP 验收

必须达到：

```text
DOCX
  ↓
转换脚本
  ↓
结构化 JSON
  ↓
校验
  ↓
UniApp 静态资源
  ↓
资料列表
  ↓
章节阅读
  ↓
题目练习
  ↓
搜索 / 收藏 / 进度
  ↓
完全离线运行
```

MVP 完成后再考虑 AI、云同步、账号和复杂题库功能。

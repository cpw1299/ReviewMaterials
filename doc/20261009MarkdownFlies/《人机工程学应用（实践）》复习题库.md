# 第二部分判断题

答题技巧：听着合理、严谨、符合常识的打√；听着绝对、离谱、太片面的打×。

第1题 正确 人机工程学是研究人、机器和环境三者之间相互关系的学科。

第2题 错误 人机工程学只研究机器性能，不关心人的因素。

第3题 正确 人机工程学的核心目标是让机器适应人，而不是让人适应机器。

第4题 错误 人机工程学就是研究怎么训练人更快适应机器。

第5题 正确 人体尺寸测量数据通常用百分位表示，第50百分位代表中等身材。

第6题 错误 设计产品时用平均身高数据就能满足所有用户需求。

第7题 正确 人体尺寸受年龄、性别、地域等因素影响，设计时要考虑目标群体特征。

第8题 错误 成年人的身高从20岁到60岁基本不会发生变化。

第9题 正确 视觉是人获取信息最重要的感觉通道，约80%的信息通过视觉获得。

第10题 错误 听觉在人机系统中的作用比视觉更重要。

第11题 正确 人的视野范围有限，重要信息应放在视野中心区域。

第12题 错误 人眼可以同时看清视野内所有位置的细节。

第13题 正确 操纵装置的设计应该符合人的操作习惯和生理特征。

第14题 错误 所有操纵装置都应设计成相同形状，方便统一操作。

第15题 正确 控制器的运动方向应与被控对象的运动方向一致，如方向盘左转车向左。

第16题 错误 控制器和显示器可以随意布局，不需要考虑对应关系。

第17题 正确 人机界面设计要考虑信息显示的清晰性、可读性和可理解性。

第18题 错误 界面上信息越多越好，用户自己会筛选。

第19题 正确 坐姿作业时，座椅高度应使大腿基本水平，小腿自然垂直。

第20题 错误 站立作业时工作台越高越好，这样可以挺直腰板。

第21题 正确 作业空间设计要考虑人的活动范围，包括最大触及范围和舒适操作范围。

第22题 错误 人的手臂可以无限伸展，作业空间不需要考虑触及范围。

第23题 正确 认知负荷是指人在处理信息时大脑所承受的负担。

第24题 错误 认知负荷越高越好，说明信息量丰富。

第25题 正确 心理模型是用户对产品如何工作的内在理解和预期。

第26题 错误 设计师的心理模型和用户的心理模型总是一样的。

第27题 正确 可穿戴设备设计要考虑佩戴舒适性、运动适应性和交互便捷性。

第28题 错误 可穿戴设备只要功能强大就行，舒不舒服不重要。

第29题 正确 老年人的人体尺寸和生理特征与年轻人不同，设计时要区别对待。

第30题 错误 残疾人的需求是少数人的需求，设计时不需要考虑。

第31题 正确 人机系统设计的目标是提高效率、保证安全和提升舒适性。

第32题 错误 人机系统设计只需考虑机器性能，人的因素不重要。

第33题 正确 显示装置设计要符合人的视觉特性，如字体大小、对比度和颜色搭配。

第34题 错误 显示装置上的文字越小越好，这样可以显示更多信息。

第35题 正确 人体测量数据有局限性，不同国家、地区、民族的数据可能不同。

第36题 错误 中国的人体尺寸数据和美国完全一样，可以直接套用。

第37题 正确 作业环境中的照明、噪音、温度等因素都会影响工作效率和舒适性。

第38题 错误 作业环境只要不太冷不太热就行，照明和噪音不影响工作。

第39题 正确 人机交互设计要关注用户的使用场景、操作习惯和心理预期。

第40题 错误 人机交互设计就是设计好看的界面，和用户习惯无关。

# 简答题

答题技巧：每题写3到5条，每条写一句话。结合生活经验回答

**第1题 请结合你的生活经验，说说什么是人机工程学，并举一个你生活中遇到的人机工程学问题的例子。**

参考思路：

1. 人机工程学是研究人、机器和环境之间关系的学科。

2. 目的是让机器适应人，让人用起来舒服、安全、高效。

3. 例子：椅子坐久了腰疼，说明椅子没有考虑人的脊柱曲线。

4. 例子：手机屏幕在阳光下看不清，说明显示设计没有考虑使用环境。

5. 人机工程学就是让产品好用、好操作、不累人。

**第2题 你平时用的椅子坐着舒服吗？请从人机工程学角度分析，一把好椅子应该具备哪些特点。**

参考思路：

1. 椅背有腰托，支撑腰椎，维持脊柱自然曲线。

2. 坐垫软硬适中，久坐不塌陷。

3. 座椅高度可调，让大腿基本水平、小腿自然垂直。

4. 扶手高度合适，手臂自然放松。

5. 椅背可后仰，缓解长时间坐姿的疲劳。

**第3题 请举例说明你生活中遇到的显示装置设计不合理的问题，并说说应该怎么改进。**

参考思路：

1. 例子：手机在阳光下屏幕看不清，亮度不够、反光严重。

2. 改进：提高屏幕亮度，增加防眩光涂层。

3. 例子：遥控器按键太小，图标看不清。

4. 改进：常用按键做大、字迹清晰、颜色对比强。

5. 例子：电梯楼层显示字体太小，老人看不清。

6. 改进：加大字体，提高对比度。

**第4题 你平时用手机时，哪些操作让你觉得不顺手？请从人机交互角度分析，并说说怎么改进。**

参考思路：

1. 例子：手机太大，单手够不到屏幕另一侧。

2. 改进：把常用功能放在拇指容易够到的区域。

3. 例子：App按钮太小，容易点错。

4. 改进：按钮至少大于手指指腹面积，通常不小于44像素。

5. 例子：指纹解锁手湿就解不开。

6. 改进：增加面部识别等多种解锁方式。

**第5题 请举例说明你生活中遇到的操纵装置设计不合理的问题，并说说应该怎么改进。**

参考思路：

1. 例子：门把手是圆球形，手湿拧不开。

2. 改进：换成杠杆式下压把手，更省力。

3. 例子：炒锅手柄太细，端起来勒手。

4. 改进：手柄加粗，增加防滑软垫。

5. 例子：水杯盖子太紧，老人拧不开。

6. 改进：增加摩擦力，或改成按压式开盖。

**第6题 你戴过可穿戴设备吗？比如智能手表、手环。请从人机工程学角度说说，好的可穿戴设备应该注意什么。**

参考思路：

1. 佩戴舒适，表带柔软贴合，不勒手腕。

2. 重量轻，不增加手腕负担。

3. 屏幕在阳光下能看清，夜晚不刺眼。

4. 操作简单，抬手就能看信息。

5. 续航时间长，不用天天充电。

6. 运动时不会滑落，防水防汗。

**第7题 你去过商场、医院、地铁站等公共场所，有没有发现空间设计不合理的地方？请举例说明并给出改进建议。**

参考思路：

1. 例子：地铁扶手太高，矮个子够不到。

2. 改进：增加拉环或降低扶手高度。

3. 例子：医院座椅没有扶手，老人起身困难。

4. 改进：加装扶手，方便起身。

5. 例子：商场洗手间洗手台太高，小孩够不到。

6. 改进：增加儿童洗手台或脚踏。

**第8题 如果你要设计一款给老年人用的手机，你会从人机工程学角度考虑哪些方面？请列出至少5点。**

参考思路：

1. 字体大，看得清，默认大字号。

2. 声音大，听得见，通话音量放大。

3. 图标简单，容易理解，不要复杂层级。

7. 手机重量轻，方便握持，不容易滑落。

# 论述题（材料分析题）

## **论述题1**

**请阅读以下材料：**

**你是一名大学生，每天上课要背很多书和电脑。你买了一个新书包，背了一天肩膀就疼得不行。你仔细观察了一下这个书包：肩带很窄，只有两厘米宽，而且没有软垫，硬边直接勒在肩膀上。书包的背部是一块硬邦邦的平板，贴着后背很不舒服，走起路来还硌得慌。你装了五本书、一个笔记本电脑和一个水杯，感觉所有重量都压在肩膀前面的两根带子上，肩膀被勒出两道红印。你试着调整肩带长度，发现调到最长还是有点短，调到最短又勒得慌，怎么都不舒服。你看到旁边同学背的书包肩带很宽，还有厚厚的软垫，背部也是透气的网面，你开始怀疑自己是不是买错了书包。**

**问题一：请从人机工程学角度，分析这个书包设计的问题出在哪里？**

参考思路：

1. 肩带太窄，压力集中在肩膀一小块区域，压强太大，容易疼。

2. 肩带没有软垫，硬边直接勒肩膀，舒适性差。

3. 背部硬板不贴合脊柱曲线，硌后背，不舒服。

4. 重量没有分散，全部压在肩膀上，没有腰带或胸带分担。

5. 肩带长度调节范围不够，不能适应不同身高的人。

6. 没有考虑透气性，背部闷热。

**问题二：如果你来改进这个书包，你会怎么设计？请说出至少两条具体方案。**

参考思路：

1. 肩带加宽加厚，增加软垫，分散压力。

2. 增加腰带或胸带，把重量分散到腰部和胸部。

3. 背部做成透气软垫，贴合脊柱曲线，不硌背。

4. 肩带长度调节范围加大，适应不同身高。

5. 内部隔层合理分布，重物靠近背部，减少力矩。

6. 肩带增加反光条，提高夜间安全性。

## 论述题2

**请阅读以下材料：**

**你每天都要用手机充电，你发现你的充电线插头是USB\-A口的，每次插都要试两次才能插对方向。插反了插不进去，你就要翻个面再插一次。有时候光线不好，你要摸半天才能找到正确的方向。你换了新手机，发现充电线是USB\-C口的，正反都能插，不用再试了，随便一插就进去了。你觉得这个设计太方便了，但你好奇为什么以前的USB\-A要设计成有方向性的。你查了一下，发现USB\-A是早期标准，当时没有考虑用户插拔的便利性，而USB\-C是后来改进的，专门解决了这个问题。**

**问题一：从人机工程学角度，分析USB\-A和USB\-C两种接口设计的差异。**

参考思路：

1. USB\-A有方向性，用户需要判断正反，增加了认知负担。

2. USB\-A插反了插不进去，用户要试错，浪费时间。

3. USB\-A在光线不好时很难判断方向，操作困难。

4. USB\-C正反都能插，取消了方向判断，操作更简单。

5. USB\-C的设计符合“不需要用户思考”的人机设计原则。

6. 好的设计应该减少用户的记忆负担和操作步骤。

**问题二：请再举一个生活中“不需要用户思考”的好设计例子，并说明它好在哪里。**

参考思路：

1. 例子：苹果的MagSafe充电，靠近就自动吸合，不用对准。

2. 好处：不需要看接口方向，不需要精确对准，随手一放就充电。

3. 例子：汽车的自动大灯，天黑自动亮，不用手动开。

4. 好处：减少操作步骤，用户不用操心，专注驾驶。

5. 例子：电梯的自动门，到站自动开，不用按按钮。

6. 好处：减少接触，方便双手拿东西的人。

7. 好的设计就是让用户“不用想”就能用对。

## 论述题3

**请阅读以下材料：**

**你去超市买了一个大西瓜，装在塑料袋里提着走回家。西瓜有五六斤重，塑料袋的提手很细，只有几毫米宽，所有重量都集中在你的几根手指上。你走了十分钟，手指被勒出两道深深的红印，火辣辣地疼。你不得不换手，但换了几次还是一样疼。你看到旁边有人用布袋子装西瓜，布袋的提手很宽，大概有三四厘米，提起来轻松很多，手掌受力均匀。你回家后想，为什么超市的塑料袋提手不能做宽一点呢？你查了一下，发现塑料袋提手做窄是为了省材料，但省了材料却让用户受罪。**

**问题一：从人机工程学角度，分析塑料袋提手设计的问题。**

参考思路：

1. 提手太细，压力集中在手指，勒得疼。

2. 没有考虑提重物时的受力面积，面积越小压强越大。

4. 没有考虑不同重量物品的需求，所有袋子提手一样细。

参考思路：

1. 提手加宽，增加受力面积，分散压力。

2. 提手加软垫，减少勒感。

3. 提手做成可调节长度，可以挎在肩上。

4. 袋子底部加硬板，重物不集中在一处。

5. 材质用结实耐磨的布料，可重复使用。

6. 提手做成两个，可以双手提，分散重量。

## **论述题4**

**请阅读以下材料：**

# 《产品设计程序与方法（实践）》复习题库

# 第一部分：答题技巧速记

选择题过关秘诀：哪个选项说得最完整、最周到就选哪个。口诀：选长不选短，选全不选偏。

判断题过关秘诀：听着合理、严谨、符合常识的打正确；听着绝对、离谱、太片面的打错误。

简答题过关秘诀：结合生活经验分条写，每条写一句话，写满5条。

论述题过关秘诀：先抄材料，再结合自己生活经验写感想。

核心逻辑：这是一门关于怎么设计出好用的东西的课。你每天都在用好用的东西、吐槽难用的东西，你已经有了判断力，只是没意识到这就是产品设计。

# 第二部分：选择题

**正确选项特征：字数最多、考虑最周全、不绝对化。**

**错误选项特征：说得太绝对、太简单、不符合日常生活经验。**

# 第三部分：判断题

**答题技巧：正确的表述：说得周全、严谨、符合你日常生活经验。错误的表述：说得太绝对、太简单、一看就不符合生活常识。**

第1题 正确 一个好的产品设计应该让用户不用看说明书就能知道怎么用。

第2题 错误 产品设计就是画漂亮的外壳。

第3题 正确 设计产品之前先了解用户有什么困扰，比直接画图更重要。

第4题 错误 设计师只需要有美术基础就够了，不需要懂用户。

第5题 正确 产品好不好用，最好的验证方法是让真实用户试用一下。

第6题 错误 设计方案越多越好，不用筛选全部做成成品。

第7题 正确 一个复杂的产品要想好用，往往需要经过多次修改和优化。

第8题 错误 好的设计都是一次性做出来的，不需要反复改。

第9题 正确 你去医院看病，从挂号到取药整个过程很顺畅，说明服务流程设计得好。

第10题 错误 产品只要功能强大就好，操作复不复杂无所谓。

第11题 正确 老年人觉得智能手机难用，往往是因为没有考虑他们的使用习惯。

第12题 错误 手机App只要功能多就是好App，好不好找没关系。

第13题 正确 磨砂材质的水杯手感更舒适，不容易滑落，这就是材料选择的意义。

第14题 错误 产品材质只影响好不好看，不影响使用体验。

第15题 正确 电梯里的关门键按了有时不立刻关门，这是为了安全考虑预留的等待时间。

第16题 错误 产品上的每一个按钮都应该一样大，这样才整齐。

第17题 正确 超市货架把同类型商品放在一起，方便你比较选购，这就是服务设计中的信息组织。

第18题 错误 设计只要好看就够了，好不好用无所谓。

第19题 正确 家里遥控器背面有手指凹槽，握起来更舒服，这就是人机工程学设计。

第20题 错误 所有产品的操作界面都应该设计得一模一样，不需要区别对待。

第21题 正确 一个好的创意往往需要在放松、不刻意想的时候才会冒出来。

第22题 错误 头脑风暴就是让大家随便聊天，不需要有规则。

第23题 正确 设计方案想得再好，不做出来试试看，永远不知道实际好不好用。

第24题 错误 做设计不需要做模型，靠想象就够了。

第25题 正确 产品设计中的做模型是为了测试和验证想法，不一定要做得很精致。

第26题 错误 原型模型做得越精美越好，花的钱越多越专业。

第27题 正确 你手机里能显示还剩多少电，这个数字就是系统在给你反馈，让你决定要不要充电。

第28题 错误 好的产品不需要给用户任何反馈，用户自己会知道。

第29题 正确 你点外卖选择不需要餐具，就是在参与减少资源浪费的可持续设计。

第30题 错误 环保是工厂的事，和普通用户没有关系。

第31题 正确 能自己换电池的手机，比不能换电池的手机更环保、更耐用。

第32题 错误 产品只要不坏就可以一直用，跟设计没有关系。

第33题 正确 你在闲鱼上卖掉旧手机，别人继续用，这就是延长了产品的使用寿命。

第34题 错误 坏了就应该直接扔掉买新的，修修补补太麻烦。

第35题 正确 一个包装盒上写着纸盒可回收，是在用文字告诉你如何处理废弃物，这是设计在管用完后的事。

第36题 错误 产品卖出去之后，怎么处理是用户的事，和设计师无关。

第37题 正确 一把好用的剪刀，握柄的形状让你自然知道手指怎么放，这就是语义在起作用。

第38题 错误 产品形状只影响审美，不影响使用感受。

第39题 正确 你拿到一个新遥控器，不用看说明就知道凸起的圆按钮是开关，这就是造型在传达功能。

第40题 错误 产品的造型和功能没有关系，造型只是为了好看。

# 第四部分：简答题

**第1题 请结合你自己的生活经验，说明了解用户需求对设计一个好产品有什么重要性。举一个生活中的例子。**

参考思路：

1. 不了解用户需求，做出来的东西可能没人用，比如老人手机字太小看不清。

2. 了解需求才能找准真正的痛点，比如垃圾桶换袋费劲是因为袋子和桶不匹配。

3. 用户自己可能说不清需求，要去观察他们的行为才能发现真问题。

4. 不同用户需求不同，要分人群设计，比如老人和年轻人的手机需求完全不同。

5. 好产品往往解决了用户没说出口的需求，比如超市购物车能上楼梯。

**第2题 请回忆你使用过的一件好用的产品，说说它为什么好用。**

参考思路：

1. 操作简单，不需要看说明书就会用，比如苹果手机。

2. 拿在手里很舒服，符合手感，比如游戏手柄的握把设计。

3. 功能实用，不多余，没有那些从来用不上的鸡肋功能。

4. 用的时候不会出错，容错性好，比如插头正反都能插。

5. 用了很久还好好的，质量可靠，比如老式诺基亚手机。

**第3题 请回忆你用过的一件难用的产品，说说它为什么难用，如果让你改，你会怎么改？**

参考思路：

1. 哪里难用，具体描述操作过程哪里卡住了，比如遥控器按键太小老按错。

2. 为什么设计成这样，猜测原因可能是为了美观牺牲了实用性。

3. 怎么改会好用，比如把常用按键做大一点，不常用的放旁边。

4. 改了之后用户会有什么体验变化，比如老人也能轻松操作了。

5. 成本会不会增加很多，其实调整按键大小基本不增加成本。

**第4题 你日常生活中，有没有遇到过被设计照顾到了的瞬间？请描述一个，并说明它为什么是好设计。**

参考思路：

1. 描述场景，比如地铁扶手的高度刚好让大部分人够得着。

2. 设计在哪里起作用，比如扶手的高度是根据平均身高设计的。

3. 如果没这么设计会怎样，比如太高了矮个子够不到。

4. 这个设计照顾了谁，比如照顾了老人、小孩和个子不高的成年人。

5. 你觉得设计师是怎么想到这个的，肯定是观察了大量乘客的使用行为。

**第5题 如果让你设计一个给老人用的智能手机，你会从哪些方面考虑？请列出至少5点。**

参考思路：

1. 字体要大，看得清楚，默认就是大字号模式。

2. 声音要大，听得见，通话和铃声都放大。

3. 图标要简单，容易理解，不要有复杂的层级菜单。

4. 操作步骤要少，每一步都有明确提示，不会迷路。

5. 按钮要大，方便手指按，不要那种很小的触控点。

6. 可以设置紧急联系人一键呼叫，遇到情况能快速求助。

**第6题 你平时使用手机App时，哪些细节会让你觉得这个App设计得真贴心？请举3个例子。**

参考思路：

1. 加载时有个小动画，不无聊，让人知道正在加载而不是死机了。

2. 点错了可以撤销，不用重新做一遍，比如邮件发送可以撤回。

3. 常用功能放在最容易点到的地方，大拇指自然覆盖的位置。

4. 晚上会自动调暗护眼模式，考虑夜间使用的舒适度。

5. 下载进度条会显示还剩多少时间，让人有预期。

**第7题 请举例说明你生活中遇到的环保类设计，并说说你对这类设计的看法。**

参考思路：

1. 举例，比如纸吸管、可降解塑料袋、自带杯买咖啡减钱等。

2. 优点，减少了塑料污染，对环境保护有实际贡献。

3. 缺点，有时体验不好，比如纸吸管泡久了会变软。

4. 改进建议，比如纸吸管可以加一层可食用防水涂层。

5. 对环保设计的整体态度，支持但要兼顾用户体验。

**第8题 假如你要买一个水杯，你会从哪些方面判断它设计得好不好？请列出至少5条。**

参考思路：

1. 手感舒不舒服，握在手里是否贴合手掌。

2. 材质安不安全，装热水会不会有异味或者释放有害物质。

3. 密封性好不好，倒放或者放包里会不会漏水。

4. 好不好清洗，杯盖和杯身能不能拆开彻底清洗。

5. 容量大小合不合适，日常使用场景需要多大容量。

6. 外观看不看，每天使用的东西要赏心悦目。

7. 价格合不合理，性价比是否合适。

8. 有没有防烫设计，有把手或者有隔热层不会烫手。

# 第五部分：论述题

答题技巧：第一步仔细读材料，圈出关键词。第二步把材料中的关键词抄进答案里。第三步结合自己的生活经验写1到2段感想。千万不要留空白，

## **论述题1**

**请阅读以下材料：**

**你家楼下新开了一家超市。你发现这家超市的购物车是可上楼梯的，轮子设计成三角形，可以轻松地在台阶上拉上拉下。你推着车上下楼买完东西，感觉非常方便。**

**问题一：请分析这款购物车的轮子设计解决了用户什么痛点？**

参考思路：

1. 解决了拎重物上下楼的痛苦，不用手提了。

2. 解决了购物车只能在平地上用的限制，现在楼梯也能用。

3. 解决了带小孩的人既要推车又要抱孩子的尴尬。

4. 让购物体验从搬货变成拉货，省力很多。

5. 老人和体力不好的人也能轻松购物了。

**问题二：如果你来设计这个轮子，你会怎么让它更好用？**

参考思路：

1. 轮子做成万向轮，拐弯更灵活方便。

2. 增加刹车功能，停在坡上不会自己溜走。

3. 轮子用静音材料，拉起来不吵。

4. 轮子可拆卸，方便清洁和更换磨损的轮子。

5. 轮子带锁定装置，推车时不会晃动。

## **论述题2**

**请阅读以下材料：**

**你买了一款新的台灯，打开包装后，你发现它不用组装，拿出来插上电就能用。灯臂是软管的，可以任意弯曲调整角度。底座很重，不会倒。**

**问题一：这款台灯的不用组装设计给用户带来了什么好处？**

参考思路：

1. 省时间，开箱即用，不用花时间研究说明书。

2. 不需要看说明书，对看不懂说明书的人很友好。

3. 不需要找工具，家里没有螺丝刀也能用。

4. 不会因为不会装而退货，减少了商家的售后压力。

5. 用户体验从折腾变成享受，打开就能用很爽。

**问题二：请分析底座重和灯臂可弯曲这两个设计分别考虑了用户的什么需求？**

参考思路：

1. 底座重考虑了稳定性，放在桌上不会倒，安全。

2. 底座重考虑了桌面空间小，底座稳可以放在任何位置。

3. 灯臂可弯曲考虑了不同场景需要不同角度，学习、玩手机、照明都能调。

4. 灯臂可弯曲考虑了不同身高的人需要不同高度，小孩大人都能用。

5. 两者结合实现了稳加灵活等于是好用。

## **论述题3**

**请阅读以下材料：**

**你的手机里有很多App。你发现微信的扫一扫功能，打开后不需要任何操作，对准二维码就自动识别了。而另一个App的扫码功能，需要先点一下开始扫描按钮才能用，你每次都要多操作一步，感觉慢了半拍。**

**问题一：对比两个App的扫码操作，哪一个设计更好？为什么？**

参考思路：

1. 微信的设计更好，少一步操作就是更好的体验。

2. 减少用户思考，自动识别比点一下再识别更自然。

3. 好的设计是默认已经做对了，不需要用户额外设置。

4. 微信的设计符合如果只有一个动作能做，就别让用户选的原则。

5. 每多一步操作就多一分放弃使用的可能。

**问题二：少一步操作的设计理念在你生活中还有哪些例子？举两个。**

参考思路：

1. 智能门锁靠近就开，不用掏钥匙翻包找钥匙。

2. 汽车感应雨刷下雨自动开，不用手动去调挡位。

3. 手机抬手自动亮屏，不用按电源键。

4. 电梯门到站自动开，不用按开门按钮。

5. 汽车大灯天黑自动亮，不用手动开灯。

## **论述题4**

**请阅读以下材料：**

**你在网上看到一款可以吃的勺子。这把勺子是用谷物和面粉做的，吃完饭顺手把勺子也吃了，不产生塑料垃圾。网上评论有人说这个创意很好，也有人说勺子泡在汤里会软，不好用。**

**问题一：可以吃的勺子体现了什么设计理念？这个理念有什么价值？**

参考思路：

1. 体现了可持续设计或环保设计的理念。

2. 减少塑料垃圾，从源头解决白色污染问题。

3. 让用完即弃变成用完即食，彻底解决废弃物问题。

4. 改变人对废弃物的看法，废弃物也可以是有用的。

5. 用设计解决环境问题，而不是靠用户自觉。

**问题二：针对泡汤会软的缺点，你觉得可以怎么改进？**

参考思路：

1. 加一层可食用防水涂层，比如蜂蜡。

2. 做成勺子柄和勺子头分开，柄硬可以吃、头可食用。

3. 加厚勺子头，延缓变软的时间。

4. 用不同配方，玉米粉混合米粉更耐泡。

5. 限定使用场景，只用于干食或凉食，热汤换别的材质。

## **论述题5**

**请阅读以下材料：**

**你在地铁站看到一个自助借书机。你可以用身份证免费借书，看完后在任意一个地铁站的同款机器上归还。你觉得这个设计很方便，而且不用专门跑一趟图书馆，上下班路上就能借还。**

**问题一：请从系统设计的角度分析这个借书机好在哪？**

参考思路：

1. 借书、还书、阅读形成一个完整的闭环系统。

2. 多个站点联网，形成网络效应，站点越多越方便。

3. 书在系统内流动，利用率大大提高。

4. 借还方便，省时间这个核心价值被充分放大。

5. 系统设计让单点的价值变成网络的价值。

**问题二：如果让你给这个系统加一个功能，你会加什么？为什么？**

参考思路：

1. 加预约功能，确认有书再去取，不白跑一趟。

2. 加推荐功能，根据借书记录推荐同类好书。

3. 加电子书选项，不想拿实体书就看电子版。

4. 加读书时长统计，看你在地铁上看了多久，增加趣味性。

5. 加换书功能，你放一本换一本，增加书源多样性。

## **论述题6**

**请阅读以下材料：**

**你买了两个保温杯。一个很贵，但用了两年保温效果还是很好。一个很便宜，但用了三个月就不保温了。贵的那个杯盖是可拆卸的，方便清洗。便宜的那个杯盖是一体的，洗不干净，里面发霉了。**

**问题一：贵的保温杯贵在哪里？请从产品设计的角度分析。**

参考思路：

1. 材料好，用的是304或316不锈钢，不是201。

2. 真空层工艺好，保温持久，两年都不衰减。

3. 结构上考虑了可拆卸清洗，卫生不藏污纳垢。

4. 密封圈质量好，不漏水，用多久都不老化变形。

5. 设计考虑了长期使用的可靠性，不是一次性产品。

**问题二：便宜的保温杯便宜在哪里？用户在使用中可能遇到什么麻烦？**

参考思路：

1. 材料差，保温效果衰减快，三个月就不行了。

2. 杯盖一体设计，清洗不了，里面发霉滋生细菌。

3. 密封圈老化快，漏水，放包里会湿。

4. 外层油漆容易掉，用几天就斑驳难看。

5. 最终便宜变成浪费，用不久就得换新的。

## 论述题7

请阅读以下材料：

你去餐厅吃饭，发现这家餐厅的菜单没有图片，只有菜名和价格。你点了两个菜，上来之后发现菜量比想象的大很多，你吃不完，浪费了食物。而另一家餐厅的菜单上，每道菜都有实物照片，还有适宜人数的提示，本菜适合2到3人。

**问题一：第二家餐厅的菜单设计比第一家好在哪里？这属于什么设计？**

参考思路：

1. 有图片知道长什么样，避免图文不符的失望。

2. 有适宜人数，不会点多了浪费食物。

3. 帮用户做决策，信息透明本身就是好的服务设计。

4. 减少食物浪费，符合可持续设计理念。

5. 用户体验从盲猜变成心中有数，点菜更自信。

**问题二：好的服务设计还可以在餐厅哪些环节体现？举两个例子。**

参考思路：

1. 等位时有排队提醒，前面还有几桌，需要等多久。

2. 扫码点餐时，菜品按热销、辣度、推荐等分类，方便选择。

3. 结账时自动显示AA制每人多少钱，不用自己算。

4. 打包盒免费或者收费合理且好用，不撒不漏。

5. 上菜时服务员主动报菜名，让你知道吃的是什么。

## 论述题8

请阅读以下材料：

你家的入户门是防盗门。你每天回家都要掏钥匙、插钥匙、转两圈、拔钥匙才能进门。有一天你换了一把智能门锁，指纹一按就开了。你觉得太方便了。

**问题一：从开门这个动作来看，智能门锁解决了传统门锁的哪些问题？**

参考思路：

1. 不用掏钥匙，不用翻包找钥匙。

2. 不用插钥匙，黑灯瞎火找钥匙孔很麻烦。

3. 不用转两圈，省力不少。

4. 不会忘带钥匙被锁在门外。

5. 出门不用带钥匙，少一样随身物品。

**问题二：你认为智能门锁有没有什么不方便的地方？如果你是设计师，你会怎么改进？**

参考思路：

1. 没电了怎么办，加紧急充电口或者用机械钥匙备用。

2. 指纹识别不了，手湿或者手脏的时候，加密码或人脸多种开门方式。

3. 担心被黑客破解，加强加密，不用联网或者联网加双重验证。

4. 家里老人指纹浅识别不了，专门优化老人指纹录入算法。

5. 太贵了，简化功能做基础款，只保留指纹和密码。

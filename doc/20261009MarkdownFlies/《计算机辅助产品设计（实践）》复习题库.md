# 判断题

# 第四部分：简答题

答题技巧：每题写3到5条，每条写一句话。结合自己的生活经验回答

**第1题 你在手机上用过修图软件，也了解过别人用3D软件建模型。请用你自己的话说说，电脑建模和手机修图有什么不同？**

参考思路：

1. 手机修图是在平面上改颜色、加滤镜，电脑建模是在三维空间里做出立体的形状。

2. 修图是改一张照片，建模是从零开始做一个立体的东西。

3. 建模做出来的东西可以转着看，从不同角度看都是立体的。

4. 修图比较简单，建模需要学一段时间才能上手。

5. 建模做出来的模型可以拿去渲染，做成效果图或者动画。

**第2题 你在网上买东西时，经常看到产品的“3D展示图”或者“360度旋转看”。请说说这种展示方式比普通照片好在哪里？**

参考思路：

1. 普通照片只能看一个角度，3D展示可以转着看，看到各个面。

2. 3D展示能看到产品的厚度、弧度、细节，比照片更真实。

3. 3D展示能让人更放心，不会买回来发现和照片不一样。

4. 3D展示是设计师用建模软件做出来的，不是拍照拍出来的。

5. 这种展示方式让网购体验更好，减少了退货。

**第3题 你见过的产品中，有没有哪个产品的“外观曲面”让你觉得特别好看？请举例说说它好看在哪里。**

参考思路：

1. 例子：苹果鼠标，曲面很流畅，没有明显的棱角。

2. 例子：汽车的侧面，曲面有光影变化，看起来很高级。

3. 好看的曲面通常是平滑的，不会突然出现折角。

4. 好看的曲面有光影过渡，亮的地方和暗的地方过渡自然。

5. 曲面好看的产品，通常是设计师用建模软件反复调整出来的。

**第4题 你平时用手机拍照，和用电脑渲染出来的产品效果图，看起来有什么不一样？请说说你的感受。**

参考思路：

1. 手机拍照是拍真实的东西，渲染图是做出来的虚拟效果。

2. 渲染图可以控制灯光、背景、角度，比拍照更自由。

3. 渲染图可以把产品放在任何场景里，比如放桌子上、放草地上。

4. 渲染图可以做得比真实产品还好看，突出产品的优点。

5. 渲染图是设计师用来展示设计方案的，不是真实拍的照片。

**第5题 如果你要给自己设计一个“手机支架”，你会怎么考虑它的形状和结构？请列出至少3点。**

参考思路：

1. 要能稳稳地撑住手机，不会倒。

2. 角度要能调节，看视频舒服。

3. 底部要防滑，放在桌上不会滑走。

4. 要方便携带，可以折叠或者做小一点。

5. 材料要轻，塑料或者铝合金都可以。

6. 外观要好看，放在桌上不丑。

**第6题 你在生活中见过哪些产品的“接缝”处理得很好？请举例说说接缝处理得好有什么好处。**

参考思路：

1. 例子：苹果耳机的充电仓，盖子合上几乎看不到缝隙。

2. 例子：汽车的车门，关上门缝隙很均匀。

3. 接缝处理得好，看起来更精致、更高级。

4. 接缝处理得好，不容易藏灰，更好清洁。

5. 接缝处理得好，说明设计师在建模时花了功夫，曲面连续性好。

**第7题 你在用电脑或手机时，有没有觉得哪个软件界面很复杂、不好用？请举例说说你觉得应该怎么改。**

参考思路：

1. 例子：有些建模软件工具太多，找不到常用的命令。

2. 改进：把常用工具放在显眼的位置，不常用的收起来。

3. 例子：有些软件按钮太小，容易点错。

4. 改进：把按钮做大一点，图标清晰一点。

5. 例子：有些软件没有中文版，看不懂英文菜单。

6. 改进：提供中文版，或者加中文提示。

**第8题 如果你要买一个台灯放在书桌上用，你会怎么选？请从外观、功能、使用感受三个方面说说你的想法。**

参考思路：

1. 外观：颜色和造型要好看，和书桌搭配。

2. 外观：不要太占地方，底座要稳。

3. 功能：亮度可以调节，看书写字用不同的亮度。

4. 功能：灯臂可以弯曲或者调节角度，方便调整照射方向。

5. 使用感受：灯光不刺眼，看久了眼睛不累。

6. 使用感受：开关方便，最好能触控或者遥控。

## 论述题1

**请阅读以下材料：**

**你在网上看到一个很漂亮的蓝牙音箱，商品页面展示了三张图：一张是正面图，一张是侧面图，还有一张是音箱放在书桌上、旁边有本书和一杯咖啡的场景图。三张图看起来都很真实，光影自然，音箱的金属网罩有细腻的质感，木纹底座也很逼真。你收到实物后发现，音箱确实和图片上差不多，但图片上的光影效果比实物更好看。你好奇这些图是怎么做出来的。**

**问题一：请说说这些商品展示图可能是怎么做出来的？它们和普通拍照有什么不同？**

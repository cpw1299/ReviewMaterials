# 复习资料文档处理方法文档

## 1. 目标

将 DOCX 等复习资料预处理成稳定的 JSON 静态资源，UniApp 运行时只负责加载、展示和记录学习状态。

```text
DOCX -> 文档提取 -> 内容规范化 -> 结构识别 -> 校验 -> JSON -> UniApp
```

核心原则：**原始文档是输入，结构化数据是产品资产，UniApp 不解析 DOCX。**

## 2. 推荐目录

```text
materials-source/
scripts/materials/
  convert_docx.py
  validate_materials.py
src/static/materials/
  index.json
  mechanical-drawing-basic.json
  assets/
```

原始 DOCX 保留，生成的 JSON 与图片独立管理。

## 3. 转换技术

推荐 Python 3.11+：

- python-docx：读取段落、样式、表格；
- lxml：必要时读取 WordprocessingML；
- Pillow：图片检查；
- pydantic：结构校验。

不要把 DOCX 解析放进 UniApp。

## 4. 两阶段模型

第一阶段先完整提取 Block，保证内容不丢失：

```json
{
  "type": "paragraph",
  "text": "投影法分为中心投影法和平行投影法。",
  "style": "Normal"
}
```

Block 类型：

```text
heading / paragraph / list_item / table / image / page_break
```

第二阶段识别语义结构：

```json
{
  "schemaVersion": 1,
  "id": "mechanical-drawing-basic",
  "title": "机械制图基础（本）-复习资料",
  "subject": "机械制图基础",
  "sections": [],
  "questions": [],
  "blocks": []
}
```

章节：

```json
{
  "id": "section-001",
  "title": "第一章 制图基本知识",
  "level": 1,
  "parentId": null,
  "blockIds": ["block-001"]
}
```

题目：

```json
{
  "id": "q-001",
  "sectionId": "section-001",
  "type": "single_choice",
  "stem": "下列投影法中属于平行投影法的是（ ）。",
  "options": [
    {"key": "A", "text": "中心投影"},
    {"key": "B", "text": "正投影"}
  ],
  "answer": ["B"],
  "analysis": "正投影属于平行投影法。",
  "tags": ["投影法"]
}
```

题型建议：

```text
single_choice / multiple_choice / true_false / fill_blank / short_answer / calculation / unknown
```

无法可靠判断时使用 `unknown`，不要强行猜测。

## 5. 识别规则

### 标题

优先使用 Heading 1/2/3；其次识别 `第一章`、`一、`、`（一）` 等模式。字号、加粗只能作为辅助。

### 题号

支持：

```text
1.  1、  （1）  1）  一、
```

### 选项

支持：

```text
A.  A、  A．  (A)
```

### 答案与解析

识别：

```text
答案：  参考答案：  正确答案：
解析：  答案解析：
```

无法可靠绑定时保留为普通 Block，并生成 WARN。

## 6. 图片与公式

图片从 DOCX media 提取到：

```text
assets/{materialId}/image-001.png
```

JSON 只保存相对路径。

公式第一版优先保证可读性；普通文本公式原样保留，复杂 OMML 可先作为原始块，后续再增加 MathML/LaTeX 转换。

## 7. 索引

`index.json`：

```json
{
  "schemaVersion": 1,
  "materials": [
    {
      "id": "mechanical-drawing-basic",
      "title": "机械制图基础（本）-复习资料",
      "subject": "机械制图基础",
      "file": "mechanical-drawing-basic.json",
      "questionCount": 120,
      "sectionCount": 8,
      "updatedAt": "2026-09-08"
    }
  ]
}
```

App 不扫描目录，只读取索引。

## 8. 命令

```bash
python scripts/materials/convert_docx.py   --input "materials-source/机械制图基础（本）-复习资料.docx"   --id mechanical-drawing-basic   --subject "机械制图基础"   --output src/static/materials

python scripts/materials/validate_materials.py src/static/materials
```

## 9. 校验

必须检查：

- JSON 可解析；
- schemaVersion 有效；
- ID 唯一；
- section/question/block 引用有效；
- 图片存在；
- 选项 key 不重复；
- 答案格式正确；
- index 中所有文件存在。

报告分为 `ERROR` 和 `WARN`。ERROR 阻止生成/提交，WARN 要求人工抽查。

## 10. 人工复核

```text
转换 -> validation -> 抽查章节 -> 抽查题目/答案 -> 检查图片 -> 修规则 -> 再校验
```

第一版坚持“规则优先 + 人工可修正”，不要一开始依赖复杂 AI。

## 11. MVP

以仓库中的《机械制图基础（本）-复习资料.docx》作为第一份样本，至少做到：

1. DOCX 成功读取；
2. 文本顺序基本不丢失；
3. 标题、正文、表格、图片形成 Block；
4. 识别明显题目、选项、答案；
5. 未识别内容仍保留；
6. 输出 material JSON；
7. 更新 index.json；
8. 校验通过；
9. UniApp 断网可读取。

后续可增加 Markdown/PDF、AI 辅助语义识别、按章节拆包和 CI 自动转换。

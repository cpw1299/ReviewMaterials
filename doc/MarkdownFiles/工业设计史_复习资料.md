
## **第一章 设计与工业设计**

【考情分析】本章每年分值14-16分，题型覆盖选择题、填空题、简答题。

#### **核心考点一：设计的本质与双重属性（★★★★★）**

1. 设计的本质：有目的地解决问题，在约束条件下创造性地满足需求

2. 设计的双重属性：

   实用属性：满足功能、技术、经济等需求

   审美属性：赋予产品以情感、文化与象征意义

3. 设计与艺术的区别：设计有明确的功能目的，艺术更注重自我表达

4. 设计与工程的区别：设计关注用户体验和审美，工程关注技术实现

#### **核心考点二：工业设计的概念与核心任务（★★★★★）**

1. 工业设计定义：针对批量化生产的工业产品，从用户需求出发，综合运用技术、艺术、经济等知识，进行功能、形态、结构、材料、工艺等方面的系统规划与设计

2. 工业设计核心任务：

   优化功能与使用体验

   塑造产品形态与品牌识别

   协调材料、工艺与成本

   关注全生命周期影响

3. 工业设计诞生的条件：批量化生产、设计与制造分离、市场竞争需求

#### **核心考点三：设计的价值维度（★★★★★）**

1. 经济价值：提升产品附加值、增强市场竞争力、缩短研发周期、降低生产成本

2. 社会价值：改善生活质量、提升公共服务效能、促进包容性设计

3. 文化价值：传承与创新文化遗产、塑造生活方式与审美风尚

4. 生态价值：推行绿色设计、降低资源消耗、倡导循环经济

#### **核心考点四：中国工业设计发展脉络（★★★★☆）**

1. 萌芽期（1950-1970s）：以工艺美术与轻工产品为主，设计意识薄弱

2. 引进期（1980-1990s）：高校设立工业设计专业，企业开始设立设计部门

3. 成长期（2000-2010s）：政策推动（中国设计红星奖）、设计公司兴起

4. 创新期（2010s至今）：设计驱动创新，中国品牌走向世界（华为、小米、大疆）

【速记口诀】设计本质解问题，双重属性实与美；工业设计批量产，功能体验品牌显；价值四维经社文生，中国四期萌引成创。

## **第二章 蒸汽时代的工业与产业**

【考情分析】本章每年分值16-20分，题型覆盖选择题、填空题、简答题。

#### **核心考点一：蒸汽时代三大技术基石（★★★★★）**

1. 动力革命：瓦特蒸汽机（万能原动机）

   使工厂脱离地理束缚，实现集中化生产

   1765年分离冷凝器，1782年双动式作功，1788年离心调速器

2. 工具革命：莫兹利全金属螺纹车床（精密制造之母）

   1800年发明，实现精密螺丝和标准化螺纹加工

   使标准化、可互换零件成为可能

3. 材料革命：钢铁的规模化生产

   科特搅炼法：生铁精炼成熟铁

   贝塞麦转炉（1856）：首次实现钢的廉价大规模生产

#### **核心考点二：工厂制度的确立与设计分化（★★★★★）**

1. 设计与制造分离：工匠时代设计与制作合一，工厂时代设计在图纸上完成，制造由机器完成

2. 标准化生产：可互换零件理念（惠特尼），为福特流水线奠定基础

3. 城市化与市场扩张：铁路和蒸汽轮船形成全球市场，产品设计趋向普适化

4. 消费社会萌芽：新兴中产阶级通过消费彰显社会地位

#### **核心考点三：1851年水晶宫博览会（★★★★★）**

1. 建筑奇迹：约瑟夫·帕克斯顿设计，铸铁+玻璃预制化建造，标准化装配典范

2. 暴露的危机：

   机器展区：功能理性，无意中形成“机器美学”

   消费品展区：装饰堆砌、风格混乱、历史主义大杂烩

   核心矛盾：先进生产技术 vs 落后审美趣味

3. 历史意义：首次将“工业化条件下设计应该是什么”的问题摆在世人面前，直接催生设计改革运动

#### **核心考点四：产业转型典型案例（★★★★★）**

1. 托耐特曲木家具（技术创新驱动新形式）

   蒸汽弯曲层压木技术（山毛榉木条蒸汽弯曲）

   第14号椅（1859）：6个部件+10个螺丝+2个垫圈，可平板包装

   首个真正成功的工业化家具，证明工业化能创造新设计语言

2. 韦奇伍德陶瓷（工业化管理+市场细分）

   标准化石膏模具、转移印花术实现装饰批量复制

   工厂化分工（70多道工序）

   产品分层：“女王牌”供贵族、“碧玉炻器”供中产、实用陶器供大众

3. 机器制造：结构理性主义，无意识的“机器美学”（Nasmyth蒸汽锤）

4. 交通工具：铁路机车（速度与进步的象征）、轮船（技术外壳+文化内装割裂）

5. 日用五金：功能主导、标准化、工业化美学（辛格缝纫机的“伪装”策略）

【速记口诀】三大基石动工材，瓦特机床贝塞麦；工厂制分设计与制造，水晶宫展矛盾显；托耐特曲木平板装，韦奇伍德模具印花术。

## **第三章 蒸汽时代的设计变革**

【考情分析】本章每年分值14-16分，工艺美术运动与新艺术运动的比较是高频考点。

#### **核心考点一：工艺美术运动（★★★★★）**

1. 理论先驱：约翰·拉斯金

   核心著作：《建筑的七盏明灯》《威尼斯之石》

   核心主张：“诚实设计”——忠实于材料、结构、功能

   推崇中世纪哥特式风格，认为其体现工匠的自由与虔诚

   对工业化的批判：机器剥夺工匠创造的乐趣

2. 实践领袖：威廉·莫里斯（现代设计之父）

   红屋（1859）：与菲利普·韦伯合作设计，裸露红砖、功能主导、材料诚实

   莫里斯商行：生产墙纸、织物、家具，坚持手工艺和天然染料

   口号：“艺术为大众”

3. 核心矛盾：民主理想 vs 精英现实——手工艺生产方式导致产品价格昂贵，只能服务富人

4. 运动影响：确立设计伦理、提高手工艺地位、启发新艺术运动

#### **核心考点二：新艺术运动（★★★★★）**

1. 核心理念：创造全新的、非历史的、属于工业时代的装饰风格

2. 风格特征：

   源于自然的有机形态（藤蔓、花卉、昆虫）

   标志性“鞭梢曲线”（纤细、流畅、富有弹性）

   “整体艺术”追求（建筑、室内、家具统一风格）

   有限度接受工业材料（铸铁、玻璃）

3. 各国表现：

   法国：赫克托·吉马德——巴黎地铁入口（铸铁模仿植物茎叶）

   比利时：维克多·霍塔——霍塔公馆（室内曲线统一）

   西班牙：安东尼·高迪——米拉之家、巴特罗之家（有机形态极致）

   奥地利：维也纳分离派（约瑟夫·霍夫曼）——几何化转向

4. 历史地位：承上启下——彻底终结历史主义循环，为现代主义清扫道路

#### **核心考点三：两大运动比较（★★★★★）**

1. 对工业化态度：工艺美术彻底否定；新艺术有限接受并尝试利用

2. 形式来源：工艺美术回归中世纪哥特；新艺术直接效法自然界有机形态

3. 核心理念：工艺美术强调道德伦理（诚实）；新艺术强调艺术美感（新风格）

4. 历史影响：工艺美术奠定设计伦理；新艺术完成与历史风格的决裂

【速记口诀】工艺美术拉斯金，诚实设计反机器；莫里斯建红屋，艺术为大众成悖论；新艺术创曲线，吉马德地铁高迪楼；两运比较看态度，否定机器vs有限接受。

## **第四章 电气时代的工业与产业**

【考情分析】本章每年分值16-18分，福特制和汽车产业是高频考点。

#### **核心考点一：电气时代核心技术集群（★★★★★）**

1. 电力：柔性动力，电动机使工厂布局解放，催生家电产业

   西门子发电机（1866）、爱迪生珍珠街电站（1882）

2. 内燃机：使个体自由移动成为可能，催生汽车产业

   奥托四冲程发动机、本茨与戴姆勒汽车

3. 新材料：合成塑料（酚醛树脂）解放产品形态

   利奥·贝克兰1907年发明酚醛树脂（电木）

   特性：绝缘、耐热、可塑性强、色彩丰富

4. 通信技术：电报、电话改变信息传递方式

   贝尔电话（1876）

#### **核心考点二：泰勒制与福特制（★★★★★）**

1. 泰勒制（科学管理，1911）

   核心：将劳动过程分解、标准化，通过时间与动作研究确定“唯一最佳方法”

   对设计影响：使设计活动本身可以被分析、优化，推动设计方法论形成

2. 福特制（流水线大规模生产，1913）

   核心：移动装配流水线，每个工人固定工位重复简单动作

   与设计的闭环逻辑：

     设计必须为制造而设计（极简结构、标准化零件）

     规模化倒逼标准化

     低成本实现大众市场

3. 福特T型车（1908-1927）

   设计哲学：“一款适合所有人的汽车”——单一型号、单一颜色（黑色）

   生产革命：装配时间从12.5小时缩短至1.5小时

   社会影响：汽车从奢侈品变为大众消费品

#### **核心考点三：通用汽车与设计职业化（★★★★☆）**

1. 阿尔弗雷德·斯隆：年度车型更换、品牌分层（雪佛兰→凯迪拉克）

2. 哈利·厄尔：首位全职汽车设计师，成立“艺术与色彩部”

3. 设计角色转变：从工程师主导到职业设计师主导，设计成为市场营销核心工具

4. 有计划商品废止制萌芽：通过外观变化刺激消费

#### **核心考点四：家电产业与材料革命（★★★★☆）**

1. 电气化家庭：电力入户催生冰箱、洗衣机、吸尘器等新品类

2. 早期家电设计特征：

   从“机器”到“家具”的伪装（冰箱做成木柜样式）

   白色成为主流（象征清洁、卫生）

3. 塑料的应用：酚醛树脂用于电话机、收音机外壳，实现一体化造型

【速记口诀】电气时代四大件，电力内燃新材料加通信；泰勒制科学管理，福特制流水线；T型车黑漆单一号，通用汽车年度换型；家电伪装成家具，塑料解放产品形。

## **第五章 电气时代的设计变革**

【考情分析】本章每年分值20-24分，是分值最高的章节，包豪斯和欧美对比是重中之重。

#### **核心考点一：德意志制造联盟（1907）（★★★★★）**

1. 核心理念：艺术、工业与手工艺相结合，通过标准化提高德国产品质量

2. 标准化辩论（1914）：

   穆特休斯派：主张彻底的标准化和类型化

   范·德·维尔德派：强调艺术家个性，担心标准化导致单调

3. 彼得·贝伦斯：德国通用电气公司（AEG）艺术顾问

   首个完整企业形象系统（标志、产品、厂房、广告统一设计）

   AEG涡轮机工厂（1909）——现代建筑里程碑

   AEG电水壶系列（1909）——标准化部件组合出多样样式

#### **核心考点二：俄国构成主义（★★★★★）**

1. 核心理念：“生产艺术”——艺术应服务于社会生产，为社会革命服务

2. 设计原则：几何抽象、动态结构、材料真实、红与黑色彩

3. 代表人物：

   塔特林：《第三国际纪念碑》（未建成），体现机器美学与动态结构

   罗德琴科：工人俱乐部设计、平面设计（对角线构图、无衬线字体）

4. 影响：设计理念传播到西欧，影响包豪斯

#### **核心考点三：荷兰风格派（★★★★★）**

1. 核心理念：“新造型主义”——用最基本的视觉元素表现宇宙普遍和谐

2. 设计原则：直线、直角、三原色（红黄蓝）+无彩色（黑白灰）、非对称平衡

3. 代表人物：

   蒙德里安：《红黄蓝构成》绘画

   里特维尔德：红蓝椅（1918-1923）——15根木条+2块木板，可拆装

   里特维尔德：施罗德住宅（1924）——开放平面、可移动隔墙、色彩平面

#### **核心考点四：包豪斯（1919-1933）（★★★★★）**

1. 核心理念：“艺术与技术：新的统一”

2. 三阶段：

   魏玛时期（1919-1925）：表现主义倾向，双轨制教学（形式大师+技术大师）

   德绍时期（1925-1932）：理性主义转向，工业化方向，黄金时代

   柏林时期（1932-1933）：密斯任校长，纳粹压力下关闭

3. 教育体系：

   基础课程（Vorkurs）：伊顿创立，材料、色彩、构成训练

   工作坊制度：木工、金属、纺织、印刷等

   理论与实践结合

4. 代表人物与作品：

   沃尔特·格罗皮乌斯：德绍校舍（功能分区、玻璃幕墙、整体设计）

   马塞尔·布劳耶：瓦西里椅（1925）——第一把钢管椅，弯曲钢管+帆布

   玛丽安·布兰特：MT8台灯（1923-24）——可调节金属臂，功能与美学结合

   赫伯特·拜耶：通用字体（1925）——无衬线小写字母

   密斯·凡·德·罗：巴塞罗那椅（1929）——“少即是多”

5. 历史意义：奠定现代设计教育基本模式，培养跨学科设计师，传播功能主义

#### **核心考点五：美国工业设计（★★★★★）**

1. 发展背景：大萧条刺激销售、大众消费社会、新材料普及

2. 核心特征：

   职业化：独立设计师顾问公司

   商业化：设计为销售服务

   流线型风格：象征速度、进步（即使静态产品也采用）

   有计划商品废止制：通过年度变化刺激重复购买

3. 雷蒙德·洛伊（MAYA原则：Most Advanced Yet Acceptable）

   代表作品：冷点冰箱（1934，销量增400%）、宾州铁路GG1机车、灰狗巴士、可口可乐瓶

4. 亨利·德雷福斯：人机工程学先驱（《为人的设计》），贝尔300型电话（1937）

#### **核心考点六：北欧现代设计（★★★★★）**

1. 核心特征：人文功能主义——功能与情感并重、自然材料、有机形态、民主设计

2. 阿尔瓦·阿尔托（芬兰）：

   弯曲胶合木技术（帕米奥椅，1931-32）

   萨沃伊花瓶（1936）——有机波浪形轮廓

3. 阿恩·雅各布森（丹麦）：

   蛋椅、蚁椅——现代材料（玻璃钢）与人体工程学结合

4. 汉斯·韦格纳（丹麦）：“Y椅”——从中国明式家具汲取灵感

#### **核心考点七：装饰艺术运动（★★★★☆）**

1. 得名：1925年巴黎“国际现代装饰与工业艺术博览会”

2. 风格特征：几何形态、奢华材料、阶梯造型、程式化自然

3. 代表作品：纽约克莱斯勒大厦（1930）——不锈钢尖塔、汽车主题装饰

4. 与现代主义关系：并存与对立，保留装饰但接受几何化

【速记口诀】制造联盟贝伦斯，AEG企业形象立；构成主义塔特林，生产艺术为社会；风格派红蓝椅，里特维尔德施罗德宅；包豪斯三阶段魏玛德绍柏林，瓦西里椅德绍校舍；美国流线型洛伊，冷点冰箱可口可乐；北欧阿尔托弯曲木，人文功能主义显；装饰艺术克莱斯勒，几何奢华阶梯形。

## **第六章 信息时代的工业与产业**

【考情分析】本章每年分值22-26分，半导体、通信演进、光伏产业是重点。

#### **核心考点一：第三次工业革命技术体系（★★★★★）**

1. 微电子技术：晶体管（1947）→集成电路（1958）→微处理器（1971）

   摩尔定律：集成电路晶体管数量每18-24个月翻一番

2. 计算机技术：大型机→个人计算机（IBM PC 1981）→软件革命

3. 通信技术：互联网（ARPANET 1969）、TCP/IP（1983）、万维网（1990）

4. 自动化技术：数控机床→工业机器人→柔性制造系统→计算机集成制造

#### **核心考点二：半导体与芯片产业（★★★★★）**

1. 晶体管优势：体积1/200、功耗1/100、寿命10万小时+、开关速度快1000倍

2. 集成电路：基尔比（德州仪器）1958年发明，诺伊斯（仙童）1959年发明平面工艺

3. 产业格局：

   设计（Fabless）：美国高通、英伟达，中国华为海思

   制造（Foundry）：台积电（全球55%+）、三星、中芯国际

   设备：荷兰ASML（EUV光刻机垄断）、美国应用材料

4. 摩尔定律产业影响：性能价格比持续提升，投资门槛极高，设计与制造分离

#### **核心考点三：无线通信演进（1G→5G）（★★★★★）**

1. 1G（1980s）：模拟语音，AMPS/NMT/TACS，砖头式“大哥大”

2. 2G（1990s）：数字语音+短信，GSM全球成功，诺基亚崛起

3. 3G（2000s）：移动多媒体，WCDMA/CDMA2000/TD-SCDMA，iPhone催化移动互联网

4. 4G（2010s）：移动宽带，OFDMA+MIMO，全IP网络，催生移动视频、支付、共享经济

5. 5G（2020s）：

   三大场景：增强移动宽带（eMBB）、超可靠低时延（uRLLC）、海量机器通信（mMTC）

   关键技术：毫米波、大规模MIMO、网络切片、边缘计算

   中国领先：华为5G专利全球第一，建成全球最大5G网络

#### **核心考点四：光伏产业（★★★★☆）**

1. 技术原理：光伏效应（1839年发现），半导体PN结光照产生电流

2. 技术路线：

   第一代晶硅电池：单晶硅（效率24%+）、多晶硅

   第二代薄膜电池：非晶硅、碲化镉、铜铟镓硒

   第三代新型电池：钙钛矿（效率从3.8%→25.7%）

3. 学习曲线效应：产量每翻一番，成本下降20-25%，1976-2020成本下降99.8%

4. 中国光伏崛起路径：

   第一阶段（2004-2011）：两头在外，制造在中国

   第二阶段（2012-2018）：多晶硅国产化突破，单晶技术路线胜出

   第三阶段（2019至今）：全球主导，各环节份额70-90%

【速记口诀】第三次工业微电计，晶体管集成电路摩尔定律；1G大哥大2G短信，3G多媒体4G宽带，5G三大场景切片边缘；光伏晶硅到钙钛矿，学习曲线成本降，中国光伏三阶段两头外到主导。

## **第七章 信息时代的设计变革**

【考情分析】本章每年分值22-24分，理性主义设计、后现代设计、服务设计是重点。

#### **核心考点一：理性主义设计与乌尔姆学院（★★★★★）**

1. 核心理念：科学性、系统性、逻辑性、功能性，形式追随功能

2. 乌尔姆设计学院（1953-1968）：

   校长：马克斯·比尔→托马斯·马尔多纳多

   教育理念：设计与科学结合，强调方法论、数学、社会学、心理学

3. 乌尔姆-布劳恩体系：

   汉斯·古格洛特、迪特·拉姆斯

   经典产品：SK4收音留声机（白雪公主的棺材）、T3口袋收音机

4. 迪特·拉姆斯“好设计十准则”：

   创新、实用、美观、易懂、克制、诚实、耐久、细致、环保、简洁

   影响：深刻影响苹果设计哲学

#### **核心考点二：后现代设计（★★★★★）**

1. 波普设计（1960s）：

   特征：大众文化、商业图像、鲜艳色彩、廉价材料

   代表：安迪·沃霍尔《坎贝尔汤罐头》、理查德·汉密尔顿拼贴画

   意义：打破高雅与低俗界限

2. 孟菲斯设计集团（1981）：

   发起人：埃托雷·索特萨斯

   理念：反设计、装饰无罪、材料实验、历史拼贴、幽默戏谑

   代表作品：卡尔顿书架（索特萨斯）、超级灯（马蒂奥·图恩）

   意义：打破功能主义教条，拓展设计可能性

3. 高技派：

   特征：暴露结构、设备管道，技术元素作为装饰

   代表：蓬皮杜艺术中心（皮亚诺+罗杰斯）、劳埃德大厦

#### **核心考点三：交互设计与用户体验（★★★★★）**

1. 交互设计定义：定义人工制品、环境、系统的行为的设计（比尔·莫格里奇）

2. 尼尔森十大可用性原则（1994）：

   系统状态可见、系统与现实匹配、用户控制自由、一致性与标准化、错误预防

   识别而非回忆、灵活高效、美学与简约、容错、帮助文档

3. 以用户为中心的设计流程：

   用户研究（访谈、观察）→人物角色→用户旅程图→原型测试

4. 用户体验五要素（杰西·詹姆斯·加勒特）：

   战略层、范围层、结构层、框架层、表现层

#### **核心考点四：服务设计与可持续设计（★★★★★）**

1. 服务设计五大原则（Marc Stickdorn）：

   以用户为中心、共创、顺序性、具象性、整体性

2. 服务设计工具：

   用户旅程图、服务蓝图、利益相关者地图

3. 绿色设计 vs 可持续设计：

   绿色设计：减少环境负面影响（材料选择、能效）

   可持续设计：环境+社会+经济三重底线

4. 可持续设计策略层级：

   产品优化→产品再设计→功能创新→系统创新

5. 循环经济设计：

   模块化设计（Fairphone）、产品服务系统（Interface地毯租赁）

【速记口诀】乌尔姆布劳恩体系，拉姆斯十准则；后现代波普孟菲斯，索特萨斯卡尔顿；交互设计莫格里奇，尼尔森十大原则；用户体验五要素战略范围结构框架表现；服务设计五大原则，用户旅程服务蓝图；可持续三重底线，循环经济模块化。

## **第八章 智能时代的工业技术与应用**

【考情分析】近5年分值22-26分，工业4.0、5G、机器人是重点。

#### **核心考点一：工业4.0（★★★★★）**

1. 定义：德国2011年提出，以信息物理系统（CPS）为核心的第四次工业革命

   纵向集成：设备层到企业层数据贯通

   端到端集成：产品全生命周期贯通

3. 五大技术支柱：

   数字化制造：数字孪生（西门子宝马生产线虚拟调试）

4. 典型应用：

   华为5G智慧矿山（井下作业减少80%）

   中兴5G智能工厂（效率提升30%）

   中国移动5G智慧港口（吞吐量提升20%）

#### **核心考点三：新能源与智慧交通（★★★★★）**

   第二代纯电动（BEV）：特斯拉Model S（2012）

3. 自动驾驶SAE分级：

   L0无自动化→L2部分自动化→L3条件自动化→L4高度自动化→L5完全自动化

4. 技术路线竞争：

   特斯拉视觉路线：仅摄像头+AI，成本低

   Waymo多传感器融合：激光雷达+摄像头+毫米波雷达，可靠性高

   华为车云一体：MDC平台+车联网+高精地图

#### **核心考点四：机器人产业（★★★★★）**

2. 工业机器人：

   类型：SCARA（装配）、六轴（焊接）、Delta（分拣）、协作机器人

   中国：2023年装机量占全球50%，埃斯顿、汇川技术、新松

   救援机器人：蛇形机器人、消防机器人

   家用：iRobot扫地机器人

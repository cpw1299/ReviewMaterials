
# 第一章 计算机辅助工业设计概述

【核心逻辑】搞清楚“用电脑做设计”这件事到底好在哪。

## 一、工业设计是什么？

工业设计不是“画得好看”，而是一门综合学科。记住这句口诀：

> “好用、好看、好造、好卖、对地球好”——五位一体，缺一不可。

具体拆开来看：

| **范畴**    | **含义**        | **示例**                     |
| --------- | ------------- | -------------------------- |
| **功能**    | 这东西能干什么用      | 吹风机能吹风、发热，把头发吹干            |
| **形态**    | 长什么样，视觉上吸不吸引人 | 戴森吹风机那个“中空圆环”造型，一看就认出是戴森   |
| **人机**    | 人拿着/用着舒不舒服    | 鼠标的弧度要贴合手掌，用一下午手腕不酸        |
| **材料与工艺** | 用什么做的、怎么做出来的  | 铝合金CNC切割 vs 普通塑料注塑，质感完全不一样 |
| **可持续**   | 环不环保、能不能回收    | 苹果说2030年所有产品碳中和，这就是可持续     |

>  � 举个例子——戴森吸尘器

| **特性分类** | **具体说明**              |
| -------- | --------------------- |
| 功能       | 吸力强，气旋技术不衰减           |
| 形态       | 枪式造型，透明集尘筒，科技感拉满      |
| 人机       | 扳机式开关，手指自然扣动，重心靠近手部不累 |
| 材料       | ABS工程塑料 + 透明PC，轻且耐用   |
| 可持续      | 滤网可水洗反复用，不用换耗材        |

这五条就是分析任何产品的“五把刀”。考试让你分析一个产品，就从这五个角度切。

## 二、产品设计流程

>  设计调研 →设计创意 → 设计深入 → 设计完成

这是逻辑上的先后顺序，但实际工作中是 反复迭代 的。比如做详细设计时发现成本超了，可能倒回去重新创意。

| **阶段** | **核心目标**   | **具体工作内容**                       |
| ------ | ---------- | -------------------------------- |
| 调研     | 发现问题、找机会点  | 看竞品、问用户、分析痛点。比如发现大家都在吐槽某款水壶盖子拧不开 |
| 创意     | 出方案、头脑风暴   | 画几十张草图，天马行空想点子，不设限               |
| 深入     | 把方案做细做准    | 定尺寸、定材质、定颜色（CMF），用Rhino建精确模型     |
| 完成     | 验证可行性、准备生产 | 3D打印手板测试，改模，出工程图，对接模具厂           |

> 举个     例子——小米手环

调研：发现很多人想要便宜、续航长、能看消息的运动手环

创意：设计了几十种腕带颜色和屏幕形状方案

深入：定下“米粒”可拆卸方案，选TPU腕带材质，定IP67防水

完成：开模试产，测试佩戴舒适度，调整腕带卡扣的松紧度

## 三、设计思维五步法

这是“以人为本”的创新流程，和上面的产品流程不一样，它强调的是 站在用户角度想问题 。

>  共情 → 定义 → 构思 → 原型 → 测试

| **步骤** | **大白话解释** | **具体操作内容**                |
| ------ | --------- | ------------------------- |
| 共情     | 把自己变成用户   | 去老人家里看他们怎么用遥控器，记录他们按错哪里   |
| 定义     | 一句话说清问题   | “老人找不到‘确认键’在哪儿，因为所有键都一样大” |
| 构思     | 天马行空出主意   | 把确认键做大、做凸、做不同颜色、做语音提示……   |
| 原型     | 快速做个样品    | 用纸板糊一个遥控器面板，按钮用不同大小贴纸     |
| 测试     | 拿给用户试试    | 给老人用，看他们能不能一秒摸到确认键，不行就重来  |

举个     例子——智能马桶盖

> -  共情 ：发现老年人冬天上厕所觉得马桶圈太冰，弯腰按按钮不方便

> -  定义 ：马桶盖需要“自动加热”和“更方便的操控方式”

> -  构思 ：座圈加热、暖风烘干、自动冲水、遥控器面板……

> -  原型 ：先做了一个带座圈加热功能的样机，找老年人试用

> -  测试 ：老人们反馈遥控器字太小看不清 → 回退到构思阶段，改成大按钮+语音播报

## 四、CAID是什么？

CAID  = Computer Aided Industrial Design，计算机辅助工业设计。

四大特点  ：

| **特点** | **大白话解释**           | **传统（无电脑）模式情况** |
| ------ | ------------------- | --------------- |
| 数字化    | 设计变成电脑里的数据文件，不会丢不会坏 | 画在纸上，一沾水就没了     |
| 可视化    | 没做出实物就能看到三维效果，转着圈看  | 只能靠手绘效果图，角度有限   |
| 参数化    | 改一个数字，相关尺寸全自动更新     | 改一个尺寸，整张图纸重新画   |
| 协同化    | 几个设计师可以同时做同一个项目     | 大家抢一张图纸，改完了传阅   |

CAID带来的三大改变：

1. 流程从线性变并行 ：以前必须等A画完B才能做，现在可以同时搞，快速迭代

2. 表达从手绘变三维渲染 ：客户不用想象，直接看渲染图，跟真的一样

3. 验证周期大大缩短 ：以前开模要等3个月才知道能不能用，现在3D打印一两天就能拿手里试

## 五、CAID常见软件（⭐⭐ 选择题常考）

| **软件**     | **功能** | **典型用途**       |
| ---------- | ------ | -------------- |
| Rhino      | 三维造型建模 | 做产品外形，鼠标、耳机、瓶子 |
| KeyShot    | 渲染出效果图 | 把模型变成照片级真实感图片  |
| SolidWorks | 工程结构设计 | 做内部结构、装配、出工程图  |

> 简单说：Rhino做“皮”，KeyShot做“相片”，SolidWorks做“骨架”。

【本章必背一句话总结】

> 工业设计是“五位一体”（功能/形态/人机/材料/可持续）；流程是“调研→创意→深入→完成”；设计思维是“共情→定义→构思→原型→测试”；CAID就是电脑让设计更快更真更方便。

# 第二章 初识 Rhino 5.0（⭐⭐ 考选择/填空）

【核心逻辑】认识Rhino这个“数字工作台”，知道哪里是哪里。

## 一、界面核心区域

| **区域** | **位置**                            | **功能**                   | **重要程度**          |
| ------ | --------------------------------- | ------------------------ | ----------------- |
| 指令栏    | 界面最上方/中间                          | 输入命令、查看操作提示，不会操作时可查看指引内容 | � 最重要，是Rhino的“大脑” |
| 视窗     | 四个格子（Top/Front/Right/Perspective） | 从顶、前、右、透视四个角度观察模型        | 建模全靠它             |
| 状态栏    | 界面最底部                             | 开启捕捉开关、显示当前坐标            | 精确建模必看            |

> 零基础理解 ：指令栏就像导航的语音提示——你不知道怎么走，它告诉你“前方100米右转”。你输入`L`，它就提示“请指定直线的起点”。

## 二、坐标输入法

坐标是告诉Rhino“点在哪里”的语言。Rhino里就考两种：

| **类型** | **输入格式** | **大白话**                     | **例子**                     |
| ------ | -------- | --------------------------- | -------------------------- |
| 绝对坐标   | X,Y,Z    | “我要去北京天安门”——从原点出发的固定位置      | 10,20,0表示从原点出发X=10、Y=20的地方 |
| 相对坐标   | rX,Y,Z   | “从我现在站的地方往东走10步”——基于当前位置的偏移 | r10,0,0表示从当前点往X轴方向走10mm    |

>  举个     例子 ：

> - 你现在在 `5,5,0` 位置，输入 `r10,0,0` → 你到了 `15,5,0`（X方向走了10mm）

> - 你在 `5,5,0` 位置，输入 `10,0,0` → 你直接飞到 `10,0,0`（回到原点附近了）

## 三、三大布尔运算

布尔运算就是把多个物体“算”成一个，像玩橡皮泥：

| **运算** | **Rhino命令**         | **效果**       | **适用场景**     |
| ------ | ------------------- | ------------ | ------------ |
| 并集     | BooleanUnion        | 两个物体捏成一个整体   | 把分开建模的几个部分合并 |
| 差集     | BooleanDifference   | 用A去减B，B的部分消失 | 挖孔、开槽，最常用！   |
| 交集     | BooleanIntersection | 只保留两个物体重叠的部分 | 做复杂的交叉切割     |

>  举个例子 ：

> - 你想在手机壳背面挖个圆孔放摄像头 → 用 差集 （手机壳 - 圆柱体）

> - 鼠标的上盖和按键分别建模 → 最后用 并集 合并成一个整体

> - 两个交叉的圆管，只要交叉部分 → 用 交集

## 四、常用变动操作（⭐⭐ 选择题）

这些就是“把东西搬来搬去、复制粘贴”：

-  移动（Move）  ：把一个东西从A搬到B

-  旋转（Rotate）  ：绕某个轴转动

-  缩放（Scale）  ：放大或缩小（注意：有等比例和非等比例两种）

-  镜像（Mirror）  ：像照镜子一样翻过去， 做对称产品（鼠标、耳机）超级好用

-  阵列（Array）  ：复制一排或一圈。 矩形阵列  = 横竖排一排； 环形阵列  = 围着圆心转一圈（比如一圈散热孔）

## 五、视图控制 & 对象选取

| **操作** | **方法**                |
| ------ | --------------------- |
| 平移视图   | 按住鼠标中键拖动              |
| 旋转视角   | 按住右键拖动（透视图中）          |
| 缩放     | 滚动滚轮                  |
| 框选     | 左键从左往右拉框 → 必须全部包住才算选中 |
| 交叉选    | 左键从右往左拉框 → 碰到就算选中     |

【本章必背一句话总结】

> 指令栏是“大脑”，状态栏是“指南针”；坐标分绝对（固定点）和相对（当前位置偏移），相对格式是  `rX,Y,Z`  绝不要写成 `r<`；布尔运算并/差/交像玩橡皮泥。

# 第三章 Rhino 建模基础

【核心逻辑】Rhino的核心是NURBS曲线，一切模型从曲线开始，曲线决定曲面质量。

## 一、NURBS是什么？（⭐⭐⭐）

NURBS  = Non-Uniform Rational B-Spline（非均匀有理B样条）。不用背全称，但要知道 两大核心优势 ：

| **优势** | **大白话**       | **为什么重要**          |
| ------ | ------------- | ------------------ |
| 数学精确   | 电脑算出来就是准的     | 模型可以直接拿去CNC加工，不会变形 |
| 局部调整   | 拽一个控制点，只影响一小块 | 改一个地方不用重做整个模型      |

> 零基础理解 ：

> 把NURBS曲线想象成一根 铁丝 ，上面焊着很多 小磁铁 （控制点）。你推拉其中一块磁铁，只有那附近的铁丝弯了，远处的不动——这就是“局部调整”。

> 对比一下：你拉一张 网格纸 （Mesh模型）的一个角，整张纸都会跟着变形，这就是NURBS比网格高级的地方。

## 二、曲线的构成要素（⭐⭐ 理解）

| **要素**   | **是什么**          | **大白话**                      |
| -------- | ---------------- | ---------------------------- |
| 控制点（CV点） | 不在曲线上 ，是用来“拽”曲线的 | 像木偶的提线，你拉线，木偶动               |
| 编辑点      | 在曲线上 ，曲线必须穿过它    | 像串珠子的线，珠子（编辑点）在线上面           |
| 阶数       | 数字越高曲线越平滑        | 1阶是折线（三角），3阶是平滑曲线（圆），但越高越难控制 |

>  举个例子 ：阶数 = 1 是三角形（硬折角），阶数 = 3 是圆形（平滑）。考试不会让你算阶数，但要懂“越高越平滑”这个关系。

## 三、曲线连续性（⭐⭐⭐ 必考！最最重要的概念！）

这是整个Rhino曲面建模的 命门 ——两条线/两个面怎么“接”才顺滑。

| **级别**   | **肉眼判定特征**        | **手感/功能特征**   | **斑马纹判定特征** |
| -------- | ----------------- | ------------- | ----------- |
| G0（位置连续） | 两条线碰在一起了，但有折角     | 摸起来有个坎        | 斑马纹断开       |
| G1（切线连续） | 接上了，没有折角，但拐弯的力道变了 | 摸起来平滑但视觉上有一条棱 | 斑马纹错位但连续    |
| G2（曲率连续） | 极致平滑，接缝处跟没接一样     | 摸不出、看也看不出接缝   | 斑马纹完美对齐且平滑  |

>  举个例子 ：

> -  G0  = 两节铁轨 没对齐 ，火车过去“哐当”一下

> -  G1  = 铁轨 对齐了 ，但接口处有个焊疤，火车过去“咯噔”一下但能走

> -  G2  = 铁轨 无缝焊接 ，打磨光滑，火车过去毫无感觉

产品应用 ：

- 刨皮刀刀刃必须  G1以上  → 否则刮起来“跳刀”，不顺滑

- 汽车车身必须  G2  → 否则高级感全无，缝隙一眼就能看出来

## 四、常用的曲线/曲面创建命令（⭐⭐⭐）

| **命令**               | **使用方法**                                    | **适用场景**          | **示意图理解**                      |
| -------------------- | ------------------------------------------- | ----------------- | ------------------------------ |
| 放样（Loft）             | 选多个横截面曲线 → Rhino自动“撑”出曲面，注意断面方向和顺序要统一，否则会扭转 | 做渐变的瓶子、花瓶         | 像用一堆不同大小的圆环撑出一个葫芦              |
| **双轨扫掠（Sweep2）�最重点** | 选两条轨道曲线（确定走向）+ 多条断面曲线（确定形状）→ Rhino铺面        | 做复杂的自由曲面：鼠标、耳机、汽车 | 像建桥：两条钢索（轨道）+ 多个横梁（断面）→ 桥面自动生成 |

>  双轨扫掠的例子 ：

> 做一个鼠标。两条轨道 = 鼠标正面轮廓线和底面轮廓线；断面 = 鼠标头部、中部、尾部的横截面形状。Rhino自动把整个鼠标“皮”给铺出来——这就是双轨扫掠的魔法。

## 五、曲面编辑核心命令（⭐⭐⭐）

| **命令**          | **作用**             | **适用场景**       |
| --------------- | ------------------ | -------------- |
| 衔接曲面（MatchSrf）  | 把两个曲面粘起来，可设G1/G2连续 | 做高端产品曲面拼接      |
| 混接曲面（BlendSrf）  | 在两个曲面之间“桥接”出一个过渡面  | 做柔和的形态过渡       |
| 曲面圆角（FilletSrf） | 给棱角倒圆              | 所有产品都必须倒角，否则割手 |
| 偏移曲面（OffsetSrf） | 做一个平行的“复制品”，保持固定距离 | 做薄壳、抽壳，实现轻量化   |

## 六、曲线/曲面质量检测工具（⭐⭐⭐）

| **工具** | **检测维度** | **合格判定标准**     |
| ------ | -------- | -------------- |
| 曲率梳    | 曲线的平滑度   | 梳齿均匀顺滑，没有突变    |
| 斑马纹分析  | 曲面的连续性   | 条纹顺滑连续，没有断开或错位 |

【本章必背一句话总结】

> NURBS两大优势：精确 + 局部调整；连续性三兄弟：G0（碰一起但折角）、G1（平滑接但有棱）、G2（完美无缝，斑马纹对齐）；曲面两大招：放样（撑出来）和双轨扫掠（沿轨道铺出来）。高端曲面看G2，双轨扫掠是神器。

# 第四章 KeyShot 渲染基础（⭐⭐ 考选择/简答）

【核心逻辑】告诉电脑“这是什么材料”，电脑按真实物理规则算出光效（PBR）。

## 一、PBR是什么？（⭐⭐⭐）

PBR  = Physically Based Rendering（基于物理的渲染）。

>  大白话 ：以前的渲染是你手动调“高光有多亮”“反射有多强”，全靠经验和手感。PBR是 你告诉电脑这是什么材料（比如不锈钢），电脑根据真实物理公式自动算出它应该怎么反射、怎么折射 。你只需要调“粗糙度”这种物理参数就行。

比如你调粗糙度=0.1，电脑自动给出“亮面金属”的效果；调粗糙度=0.8，自动给出“磨砂金属”的效果。

## 二、四大核心材质参数

| **参数**   | **控制什么**        | **数值/例子**                   |
| -------- | --------------- | --------------------------- |
| 漫反射      | 物体本来的固有色        | 红色塑料就是红色漫反射                 |
| 粗糙度      | 表面光滑还是磨砂        | 0=镜面（光可鉴人），1=粗砂纸（完全哑光）      |
| 折射率（IOR） | 光线穿过透明物体时怎么“拐弯” | 空气=1.0，水≈1.33，玻璃≈1.5，钻石≈2.4 |
| 凹凸/法线    | 表面纹理（用贴图“骗”眼睛）  | 模型的几何不变，但看起来有荔枝纹、木纹         |

## 三、三大基础材质

| **材质** | **关键参数**                | **适合用途**   |
| ------ | ----------------------- | ---------- |
| 塑料     | 漫反射 + 粗糙度               | 绝大多数产品外壳   |
| 金属     | 漫反射（基础色）+ 粗糙度（极低）+ 环境反射 | 不锈钢、铝、铜    |
| 玻璃     | IOR（折射率）最关键 + 粗糙度       | 透明产品、镜头、灯泡 |

>  举个例子 ：

> - 一个 磨砂白色塑料壳 ：漫反射=白色，粗糙度=0.4

> - 一个 亮面不锈钢 ：漫反射=银灰色，粗糙度=0.05，环境光要丰富才好看

> - 一个 透明玻璃杯 ：IOR=1.5，粗糙度=0，折射打开

## 四、五大贴图类型/映射模式

贴图就是把一张平面图片“包”到3D模型上。不同类型的映射适合不同形状：

| **映射类型** | **适用形状** | **示例**    |
| -------- | -------- | --------- |
| 平面映射     | 平面或轻微弧面  | 平面上的Logo  |
| 盒映射      | 方方正正的盒子  | 包装盒六个面    |
| 球形映射     | 球体       | 地球仪、球类    |
| 圆柱形映射    | 圆柱体      | 保温杯的标签、瓶子 |
| UV映射     | 不规则自由曲面  | 鼠标上的防滑纹理  |

>  记住这个例子 ：给保温杯贴一圈标签 → 用 圆柱形映射 。这是考试最爱考的场景。

## 五、【项目】面板五大选项卡（⭐⭐）

| **选项卡** | **管理内容**     |
| ------- | ------------ |
| 场景      | 模型本身 + 环境背景  |
| 材质      | 给模型赋什么材料     |
| 环境      | 灯光怎么打、HDR环境图 |
| 相机      | 从哪个角度看、焦距、景深 |
| 图像      | 输出分辨率、曝光、对比度 |

## 六、渲染设置关键参数（⭐⭐）

| **参数** | **作用**     | **注意事项**                   |
| ------ | ---------- | -------------------------- |
| 分辨率    | 图片大小（像素）   | 1920×1080是高清，4000×4000是印刷级 |
| 采样值    | 越高噪点越少、越清晰 | 越高渲染越慢，一般设置50-200          |
| 降噪     | 自动去除噪点     | 开启后效率大增，建议开启               |

## 七、灯光材质（⭐⭐）

| **灯光类型** | **效果**       | **适用场景**     |
| -------- | ------------ | ------------ |
| 区域光      | 柔和阴影，像摄影棚柔光箱 | 最常用，室内产品打光首选 |
| 针状光/小点光  | 锐利高光，阴影硬     | 表现不锈钢镜面的锐利反射 |
| HDR环境光   | 模拟真实环境的全局光照  | 产品渲染最常用的光照方式 |

>  重要更正 ：如果要表现 不锈钢高光条纹（锐利的）  ，用 针状光 或 小半径点光 ，不是区域光！区域光出的是柔和高光。

## 八、关于硅胶材质的特别提醒

>  很多同学会写“硅胶 = 塑料材质 + 次表面散射（SSS）” —— 这是错的！

KeyShot标准 “塑料”材质没有SSS通道 。正确做法是：

> - 使用  “半透明材质（Translucent）” 或  “漫反射材质（Diffuse）”  并开启SSS

> - 或者直接用材质库里的  “软胶（Silicone/Soft Touch）”  预设

> 硅胶的特点是半透明、亲肤、光线能透进去一点点，所以要用SSS来模拟那种“透光感”。

【本章必背一句话总结】

> KeyShot核心是PBR（物理渲染）；材质四大参数 = 漫反射（固有色）+ 粗糙度（光滑/磨砂）+ IOR（折射率）+ 凹凸（纹理）；三大材质 = 塑料 + 金属 + 玻璃；贴保温杯标签用 圆柱形映射 ；硅胶用半透明材质（带SSS），不是塑料。

# 第五章 小产品建模渲染实例（刨皮刀）（⭐⭐⭐ 考简答/综合）

【核心逻辑】把第3、4章的抽象概念用到具体产品上，用实际案例说明“建模有什么用”。

## 一、连续性对功能的影响（⭐⭐⭐）

>  刀刃必须G1以上连续  → 否则刮皮的时候会“跳刀”，一下深一下浅，用户体验极差。

考试答题模板 ：刨皮刀的刀刃曲面，在建模时必须使用 衔接曲面（MatchSrf）  或 双轨扫掠 保证G1以上连续性，并在KeyShot中用 斑马纹 检测确认。G0的刀刃在斑马纹上会显示条纹断开，反映到功能上就是切削不顺滑。

## 二、布尔运算的应用

| **操作**     | **布尔运算类型** | **实际场景**           |
| ---------- | ---------- | ------------------ |
| 在刀身上挖安装槽   | 差集         | 刨皮刀要装刀片进去，得有槽      |
| 把锯齿合并成整体   | 并集         | 多个锯齿分别建模，最后合并成一个刀头 |
| 在刀柄上挖防滑纹凹槽 | 差集         | 用纹理形状去减刀柄表面        |

>  � 举个例子 ：刨皮刀的刀片安装槽，就是先建一个刀片形状的实体，再用“刀身 - 刀片实体”（差集），完美挖出形状吻合的槽。

## 三、薄壁结构

用偏移曲面（OffsetSrf）做一个外壳，厚度一般0.5mm-2mm。

>  为什么要做薄壁？  产品要轻量化，省材料，还要给内部零件（如刀片卡扣）留空间。全实心的产品既重又浪费材料，也不真实。

考试答题模板 ：刨皮刀刀体使用 偏移曲面 命令，向内偏移0.5-1.0mm，形成薄壁外壳结构，实现产品轻量化设计，同时为内部刀片组件提供安装空间。

## 四、防滑纹建模流程

>  绘制纹理 → 阵列 → 投影到曲面 → 沿曲面流动（FlowAlongSrf）

这里的核心是  “沿曲面流动”  ：你在平面上画的纹路（比如菱形格子），用这个命令可以完美“贴”到弯曲的刀柄表面上，纹路跟着曲面走，不会变形。

考试答题模板 ：刀柄防滑纹的建模流程为：①在平面上绘制菱形纹理单元 → ②使用矩形阵列复制成纹理网格 → ③将纹理 投影 到刀柄曲面 → ④使用 沿曲面流动（FlowAlongSrf）  命令，使纹理精确贴合曲面。

## 五、合模线

注塑产品上那条细细的“脊”，是模具上下两半闭合的痕迹。建模时用 0.1-0.2mm微小凸起 表现，边缘倒圆角。

## 六、贴图通道综合应用

用一张黑白贴图，同时接入 凹凸通道 和 粗糙度通道 ：

- 白色区域 → 凹下去 + 粗糙（磨损处）

- 黑色区域 → 平整 + 光滑（未磨损处）

>  效果 ：刀身用久了有划痕和磨损，磨损处更粗糙、反光更弱，这样金属就有了“故事感”，不是全新的工业品，而是被用过的、真实的工具。

## 【本章必背一句话总结】

> 刨皮刀实例 = 刀刃G1连续保顺滑 + 布尔差集挖槽装刀片 + 偏移曲面做薄壁轻量化 + 流动命令贴防滑纹 + 贴图通道模拟磨损。三个“性”：建模的功能性、细节的工艺性、渲染的材料性。

# 第六章 数码产品设计实例（打印机/投影仪）（⭐⭐⭐ 考综合）

【核心逻辑】数码产品设计不是“拍脑袋长出来的”，而是由CMF、人机、结构、语义 共同推导 出来的。

## 一、CMF驱动分件 + 美工线

CMF  = Color（色彩）+ Material（材料）+ Finishing（工艺）。

>  什么叫“分件”？

> 一台打印机，前面板是 白色亮面塑料 ，侧盖是 灰色磨砂塑料 ，操作面板是 黑色钢琴烤漆 ——三种不同颜色/材料的零件，不可能长成一个整体，所以必须分开建模。

分件之间的那条缝，叫“美工线”  （也叫分件槽）：

| **概念** | **是什么**                | **怎么建模**                    |
| ------ | ---------------------- | --------------------------- |
| 美工线    | 主动设计的凹槽，用来区分不同材质/颜色的零件 | 建模时在零件交界处做一条0.5-1mm宽的凹槽     |
| 分模线    | 工艺残留，模具开模留下的痕迹         | 建模时尽量隐藏或做小，实在不行用0.1-0.2mm凸起 |

>  考试重点 ：美工线是 主动设计的装饰 ，分模线是 被动留下的痕迹 。前者是美学，后者是工艺。

举个例子 ：iPhone 4的不锈钢中框和前后玻璃面板之间那条细细的缝隙，就是美工线——它在告诉你“这里是金属和玻璃的交界处”。

## 二、人机交互面布局

屏幕和按键必须在 用户的正面视野内 + 手指自然可及的区域 。

 打印机例子 ：

> - 控制面板一定在 打印机前方偏上 ——用户站着操作，屏幕刚好在视线水平

> - 按键间距不小于 8mm ——防止手指粗的人误触

> - USB接口在前方或侧面伸手可及处——不用钻到机器后面去插

>  

 这叫“结构合理性”——每一个特征的位置，都是有依据的，不是随便放的。

## 三、功能特征形态化

散热孔、镜头、接口这些功能件， 不要当“补丁”一样贴上去 ，要让它们成为设计语言的一部分。

投影仪例子 ：

> -  镜头  = 视觉中心，是“眼睛”，必须突出，周围做同心圆环装饰

> -  散热格栅  = 设计成动感线条，从侧面延伸到后面，像跑车的进气口

> -  指示灯  = 镶嵌在美工线里，不额外开孔

>  

>  答题模板 ：“该投影仪将散热孔设计为参数化渐变的斜向格栅，既满足空气对流需求，同时通过阵列元素形成速度感的视觉符号，实现了功能与形态的融合。”

## 四、形态语义

产品造型会“说话”——用户看到形状就能猜到它的性格。

| **造型倾向** | **语义（用户感觉）** | **适用产品**   |
| -------- | ------------ | ---------- |
| 前倾、有棱角   | 主动、高效、专业     | 办公打印机、游戏设备 |
| 圆润、曲线多   | 亲和、家居、安全     | 家用电器、儿童产品  |
| 极简、方正    | 现代、科技、冷静     | 苹果风格产品     |

>  举个例子 ：戴森风扇那个“无叶”圆环造型 → 语义是“未来感、黑科技”；小米空气净化器那个圆润柱体 → 语义是“简约、家居百搭”。

## 五、场景化渲染

渲染不是把产品“立正站好”拍个白底图就完了，而是 把产品放在它的使用环境里 。

>  � 投影仪  → 必须在 暗环境 下渲染，加上 体积光（光锥效果）  ，屏幕投射出画面。这样一眼就能看出“这是个投影仪”。

> 

> 如果放在亮堂堂的摄影棚里，投影仪跟个黑色方盒子没区别，谁也不知道它是干嘛的。

## 六、环境光遮蔽（AO）

AO  = Ambient Occlusion（环境光遮蔽）。

>  什么效果？  让模型缝隙、转角、零件交界处有自然的阴影，看着更“扎实”、更有体积感。没有AO的效果是“飘”在画面上的。

> 

> KeyShot里直接勾选开启就行，不用调参数。

答题模板 ：“在产品渲染中开启 环境光遮蔽（AO）通道 ，能够增强模型转折面的立体感，使形体关系更加清晰，视觉上更加真实、厚重。”

## 七、打印机实例建模常用命令

| **命令**      | **适用场景**           |
| ----------- | ------------------ |
| 放样（Loft）    | 打印机主体曲面（有机形态的机身）   |
| 布尔差集        | 屏幕凹槽、散热孔、接口开孔      |
| 投影（Project） | 在曲面上精确定位Logo、指示灯位置 |
| 挤出（Extrude） | 出纸托盘、进纸槽           |

建模逻辑 ：先做“大面”（主体外壳），再做“细节”（按键、屏幕槽、散热孔），最后做“分件”（用布尔差集切出美工线沟槽）。

【本章必背一句话总结】

> 数码产品设计 = CMF驱动分件（美工线区分材料）+ 人机约束布局（按键屏幕在好用的位置）+ 功能形态化（散热孔变设计元素）+ 语义表达（前倾=高效，圆润=亲和）+ 场景化渲染（投影仪配体积光）。每一处设计都要有“为什么”。答综合题就按这个逻辑展开。

# 第七章 小家电建模渲染实例（剃须刀/电熨斗）（⭐⭐⭐ 综合大题大结局）

【核心逻辑】把人机工学、多材料建模、情境渲染全部融合，考的就是“综合能力”。

## 一、人机工学 → 形态的具体转化（⭐⭐⭐）

>  剃须刀手柄为什么是“腰鼓形”？（两头粗、中间细）

因为人手握拳时，虎口和掌心形成一个“环”，腰鼓形刚好贴合这个环 ：

| **手的部位**     | **手柄对应位置** | **形状要求**     |
| ------------ | ---------- | ------------ |
| 虎口（大拇指和食指之间） | 手柄上端       | 饱满贴合，防止前后滑   |
| 掌心（握拳时凹陷处）   | 手柄中部       | 弧线收窄，刚好卡在掌心里 |
| 小指侧（手掌根部）    | 手柄下端       | 微翘或加粗，防止脱手   |

怎么用Rhino表达 ？

- 用 放样 或 双轨扫掠 ，控制断面形状从圆→扁圆→圆的渐变

- 用 控制点 拉出腰鼓曲线

- 不断用3D打印手板让人握持测试，调整到舒服为止

>  考试答题模板 ：“该剃须刀手柄采用腰鼓形曲面设计，通过 双轨扫掠 构建从头部到尾部的渐变断面，截面直径变化范围为32mm-28mm-32mm，精确贴合人体虎口与掌心的凹陷区域，并利用 控制点调形 优化握持弧度，有效防止产品在使用中的旋转滑脱。”

## 二、多材料建模与装配

> “硬塑骨架 + 软胶皮肤”——这是小家电的经典结构。

怎么建模？     

| **步骤** | **操作内容**                | **Rhino命令** |
| ------ | ----------------------- | ----------- |
| 1      | 制作硬质ABS塑料内壳（建骨架）        | 偏移曲面做薄壁     |
| 2      | 在骨架上标记软胶包裹区域            | 分割曲面（Split） |
| 3      | 在标记区域覆盖一层TPU软胶          | 偏移曲面 + 布尔并集 |
| 4      | 留装配间隙：软胶比硬胶缩进去0.1-0.3mm | 偏移曲面（负值）    |

为什么要缩进去0.1-0.3mm？     

> 因为软胶（TPU）是二次注塑上去的，必须有“缝”让融化的塑料流进去。如果建模时分件面是零间隙（完全贴死），实际生产时就会“溢胶”或“装不进去”。     这就是工程合理性——建模不是画着好看，是要能生产的。     

## 三、防滑纹理的精确贴合

与刨皮刀类似，剃须刀手柄上的软胶防滑纹也要用      “沿曲面流动（FlowAlongSrf）”      命令。流程：

> 画纹理（平面）→ 阵列复制 → 投影到曲面 → 沿曲面流动（贴合）     

纹理一般是菱形或六边形凸点，阵列布满手柄软胶区域，再用Flow命令让纹理跟着手柄的弧度走，完美贴合。

## 四、情境化渲染

>   “情境化” = 产品不是在“空房间里”拍照，而是在“真实使用场景”里展示。

| **产品** | **加什么特效** | **为什么**             |
| ------ | --------- | ------------------- |
| 剃须刀    | 水珠        | 告诉用户“全身水洗”情景暗示功能可视化 |
| 电熨斗    | 蒸汽、衣物褶皱   | 告诉用户“能熨平衣服”         |

零基础理解     ：

> - 拍美食要加“热气”（看起来刚出锅）

> - 拍饮料要加“水珠”（看起来冰爽）

> - 拍剃须刀要加“水珠”（看起来能水洗）

> 

这就是情境化——产品不是在展示“它长什么样”，而是在讲“它怎么用”。

## 五、高光质感塑造

表现不锈钢底板（如电熨斗底部），要：

> - 粗糙度 = 0.05-0.15（极低）

> - 用区域光打出柔和的高光条纹（宽幅连续高光）

> - 环境反射要丰富，让金属“活”起来

重点 ：高光的形状和边缘清晰度，是材质真实感的关键。柔和高光 = 拉丝不锈钢 + 区域光；锐利高光 = 镜面不锈钢 + 小光源（第4章讲过）

## 六、功能分区

电熨斗按温度从低到高分三个区域：

| **分区**  | **位置**  | **温度范围（单位：℃）** | **材料要求**           |
| ------- | ------- | -------------- | ------------------ |
| 底板（高温区） | 最底部接触衣物 | 100-200        | 不锈钢，耐高温            |
| 主体（缓冲区） | 中部水箱    | 40-60          | 透明PC/PP塑料，耐温100℃以上 |
| 手柄（安全区） | 最顶部手握持  | 室温-30          | ABS塑料，隔热设计         |

考试逻辑 ：温度高的地方用金属 + 散热结构；安全区用塑料 + 防滑纹理。一切设计从“这地方多烫”出发。

## 七、安全设计

所有外露边缘必须倒圆角（R角）      ——这是基本功中的基本功。

- 手柄边缘 R≥0.5mm（人手握持舒适）

- 锐角必须完全消除，不能有尖角

- 按钮和按键的边缘也要倒角，防止划伤手指

## 八、产品姿态

渲染时不要把产品“立正站好”（死板的正视图），要给它一个     生动的角度     ：

- 剃须刀微微倾斜，刀头旋转15° → 暗示“它正在工作”

- 电熨斗斜靠在熨衣板上 → 暗示“正在使用中”

- 背景加手部模型握持 → 一目了然展示人机关系

# 【本章必背一句话总结】

> 小家电设计 = 人机工学推形态（腰鼓手柄贴虎口）+ 多材料建模分软硬（软胶缩进0.1-0.3mm留间隙）+ 防滑纹精准贴合（沿曲面流动）+ 情境化渲染讲故事（水珠/蒸汽）+ 高光质感（低粗糙度+区域光）。每一处细节要么让人“握着舒服”，要么让人“看着真实”。

终极考前叮嘱

## 一、简答题万能模板

看到“分析某个产品设计”的题，按这个框架答，分点分条，老师按点给分     ：

> 1. 功能 ：这个产品能干什么……

> 2. 形态 ：它长什么样，为什么长这样……

> 3. 人机 ：人怎么用它，哪里握着舒服……

> 4. 材料/工艺 ：用什么做的，怎么造出来……

> 5. 可持续 ：环保方面怎么考虑的……

## 二、建模类简答题万能模板

看到“怎么做某个造型/纹理”的题：

> 1. 先建主体曲面（用什么命令）

> 2. 再处理细节（布尔差集开孔/倒角/分件）

> 3. 最后做纹理或特征（沿曲面流动/阵列/投影）

> 4. 质量检测（斑马纹检查G2连续性）

## 三、渲染类简答题万能模板

看到“怎么表现某种材质”的题：

> 1. 选什么材质类型（塑料/金属/玻璃/半透明）

> 2. 调什么参数（漫反射颜色/粗糙度/IOR/凹凸贴图）

> 3. 打什么光（区域光柔和/针状光锐利/HDR环境）

> 4. 加什么特效（AO/贴图通道/体积光）

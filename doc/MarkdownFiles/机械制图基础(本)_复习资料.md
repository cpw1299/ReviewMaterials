
# 第一章 制图的基本知识

## 【1.1 国家标准的基本规定】

### 一、图纸幅面

A0（841×1189）、A1（594×841）、A2（420×594）

A3（297×420）、A4（210×297）

A1面积为A0的一半，依此类推

### 二、比例

原值比例：1:1

放大比例：2:1、5:1等

缩小比例：1:2、1:5等

### 三、字体

汉字：长仿宋体，高度h≥3.5mm

数字和字母：可直体或斜体（斜体字头向右倾斜75°）

### 四、图线（8种常用）

**图线相关信息表**

| **图线名称** | **线型** | **主要用途** |
| -------- | ------ | -------- |
| 粗实线      | 连续粗线   | 可见轮廓线    |
| 细实线      | 连续细线   | 尺寸线、剖面线  |
| 虚线       | 断续细线   | 不可见轮廓线   |
| 点画线      | 细点划线   | 轴线、对称中心线 |
| 双点画线     | 双点划线   | 相邻辅助零件   |
| 波浪线      | 波浪线    | 断裂边界     |
| 双折线      | 双折线    | 断裂边界     |
| 粗点画线     | 粗点划线   | 特殊要求     |

### 五、尺寸标注基本规则

1. 尺寸数字写在尺寸线上方或中断处

2. 线性尺寸数字：水平朝上，垂直朝左

**3****，****角度尺寸线为圆弧，数字水平书写在尺寸线中断处或上方。**

4，直径标"φ"，半径标"R"，球面标"Sφ"或"SR"

## 【1.2 几何作图】

### 一、斜度

一直线（或平面）对另一直线（或平面）的倾斜程度

标注为"∠1:n"

### 二、锥度

圆锥底面直径与高度之比

标注为"◁1:n"

### 三、圆弧连接

关键是准确找出连接圆弧的圆心和切点

## 【1.3 平面图形的作图方法及尺寸标注】

### 一、尺寸分析

定形尺寸：确定形状大小的尺寸

定位尺寸：确定各部分相对位置的尺寸

尺寸基准：标注定位尺寸的起点

### 二、线段分析

已知线段：定形、定位尺寸齐全，可直接画出

中间线段：有一个方向定位尺寸缺失

连接线段：两个方向定位尺寸均缺失

### 三、平面图形作图步骤

画基准线 → 画已知线段 → 画中间线段 → 画连接线段 → 检查整理

### 四、徒手绘图

徒手画直线：眼睛注视终端，手腕悬空，从左到右画

徒手画圆：先画中心线，再画正方形，最后画圆

# 第二章 正投影基本知识

## 【2.1 三投影面体系与三视图】

### 一、三投影面体系

V 面（正立投影面）→ 主视图（从前向后看）

H面（水平投影面）→ 俯视图（从上向下看）

W面（侧立投影面）→ 左视图（从左向右看）

### 二、三视图投影规律（重点记忆）

【长对正】：主、俯视图长度相等

【高平齐】：主、左视图高度相等

【宽相等】：俯、左视图宽度相等

### 三、方位对应关系

主视图：反映上下、左右

俯视图：反映左右、前后

左视图：反映上下、前后

## 【2.2 点的投影】

### 一、点的三面投影

空间点A(x,y,z) → **正面投影 a'、水平投影 a、侧面投影 a''**

### 二、点的投影规律

a a' ⊥ OX轴

a' a" ⊥ OZ轴

### 三、重影点

空间两点在某投影面上的投影重合

判断可见性：坐标值大的可见

不可见的点加括号表示

## 【2.3 直线的投影】

### 一、直线分类

#### 1. 投影面平行线（平行于一个投影面）

- 水平线（∥H）：水平投影反映实长

- 正平线（∥V）：正面投影反映实长

- 侧平线（∥W）：侧面投影反映实长

#### 2. 投影面垂直线（垂直于一个投影面）

- 铅垂线（⊥H）：水平投影积聚为点

- 正垂线（⊥V）：正面投影积聚为点

- 侧垂线（⊥W）：侧面投影积聚为点

#### 3. 一般位置直线：三个投影均倾斜

### 二、直线上的点

点的投影在直线的同面投影上，且符合定比性

### 三、两直线相对位置

平行、相交、交叉

### 四、直角投影定理

两直线垂直（相交或交叉），且其中一条平行于某投影面时

在该投影面上的投影仍垂直

### 五、直角三角形法求实长

**直角三角形相关参数表格**

| **所求参数**  | **计算所需条件**   |
| --------- | ------------ |
| 实长及与H面夹角α | 水平投影长 + z坐标差 |
| 实长及与V面夹角β | 正面投影长 + y坐标差 |
| 实长及与W面夹角γ | 侧面投影长 + x坐标差 |

## 【2.4 平面的投影】

### 一、各种位置平面的投影特点

**平面类型与投影特性表**

| **平面类型** | **投影特性**  |
| -------- | --------- |
| 水平面(∥H)  | 水平投影反映实形  |
| 正平面(∥V)  | 正面投影反映实形  |
| 侧平面(∥W)  | 侧面投影反映实形  |
| 铅垂面(⊥H)  | 水平投影积聚为斜线 |
| 正垂面(⊥V)  | 正面投影积聚为斜线 |
| 侧垂面(⊥W)  | 侧面投影积聚为斜线 |
| 一般位置平面   | 三个投影均为类似形 |

### 二、平面上的点和直线

点在平面上：必在该平面的一条直线上

直线在平面上：过平面上的两点，或过一点平行于平面上一直线

### 三、应用

直线与平面相交：求交点，判断可见性

平面与平面相交：求交线，判断可见性

# 第三章 基本形体的投影与立体表面交线

## 【3.1 平面立体的投影】

### 一、棱柱

投影特点：上下底面为多边形（反映实形），棱线为垂直线

表面取点：利用积聚性

### 二、棱锥

投影特点：底面为多边形，侧面为三角形

表面取点：辅助线法（过锥顶作辅助线）

### 三、平面体切割（截交线）

截交线是封闭的平面多边形

作图步骤：求交点 → 连点 → 判断可见性

## 【3.2 曲面立体的投影】

### 一、圆柱

形成：母线绕平行轴线旋转

投影：一个圆（积聚性）+ 两个矩形

表面取点：利用积聚性

### 二、圆锥

形成：母线绕相交轴线旋转

投影：一个圆 + 两个三角形

表面取点：辅助素线法、辅助圆法（纬圆法）

### 三、球体

形成：半圆绕直径旋转

投影：三个投影均为等径圆

表面取点：辅助圆法（水平圆、正平圆、侧平圆）

### 四、曲面体切割（截交线）

**形体截交线信息表**

| **形体** | **截平面位置**  | **截交线形状** |
| ------ | ---------- | --------- |
| 圆柱     | 平行于轴线      | 矩形        |
| 圆柱     | 垂直于轴线      | 圆         |
| 圆柱     | 倾斜于轴线      | 椭圆        |
| 圆锥     | 垂直于轴线      | 圆         |
| 圆锥     | 倾斜(θ>α)    | 椭圆        |
| 圆锥     | 平行于素线(θ=α) | 抛物线       |
| 圆锥     | 平行于轴线(θ=0) | 双曲线       |
| 圆锥     | 过锥顶        | 三角形       |
| 球体     | 任意         | 圆         |

## 【3.3 立体与立体相交】

### 一、相贯线概念

两立体表面相交产生的交线

### 二、相贯线性质

封闭的空间曲线（一般情况）

共有线（同时属于两立体表面）

### 三、特殊情况

两等径圆柱正交时，相贯线为两个垂直的椭圆

### 四、求相贯线的方法

积聚性法、辅助平面法

# 第四章 组合体

## 【4.1 组合形式及表面连接关系】

### 一、组合形式

叠加、切割、综合

### 二、表面连接关系

平齐（共面）：无线

**光滑相切：无线（注意区分直角相切与圆弧相切）**

相交：有交线（直线或曲线）

## 【4.2 组合体画图】

### 一、分析方法

形体分析法：假想把组合体分解为若干基本形体

线面分析法：分析各表面的投影

### 二、画图步骤

选主视图 → 定比例、图幅 → 画基准线 → 逐个画基本形体 → 检查、加深

### 三、主视图选择原则

反映形状特征最明显

符合工作位置

## 【4.3 组合体尺寸标注】

### 一、基本要求

正确、完整、清晰

### 二、尺寸分类

定形尺寸：确定基本形体大小的尺寸

定位尺寸：确定基本形体相对位置的尺寸

总体尺寸：确定总长、总宽、总高的尺寸

### 三、尺寸基准

长、宽、高三个方向的基准

（对称面、底面、端面、轴线等）

### 四、注意事项

避免封闭尺寸链

标注清晰，便于测量

## 【4.4 组合体读图】

### 一、读图方法

形体分析法：分线框、对投影、想形状

线面分析法：分析复杂交线、斜面的投影

### 二、读图要点

从特征视图入手

多个视图对照看

注意虚实线变化

利用"三等"规律

### 三、应用

根据两个视图补画第三视图

# 第五章 工程图样的表达方法

## 【5.1 视图】

### 一、基本视图

主、俯、左、右、仰、后六个视图

中国采用第一角画法

### 二、向视图

可以自由配置的基本视图

需标注投影方向和名称

### 三、局部视图

只画机件某一部分

用波浪线或双折线断开

### 四、斜视图

表达倾斜结构

向不平行于基本投影面的平面投影

## 【5.2 剖视图】

### 一、剖视图概念

假想用剖切平面剖开机件

移去观察者与剖切面之间的部分

画出剩余部分的投影

### 二、剖面符号

金属材料用45°细实线（同一零件方向一致）

### 三、剖视图种类

全剖视图：用剖切平面完全剖开机件

半剖视图：一半画剖视，一半画视图（用于对称机件）**注意：当轮廓线与细点画线重合时，分界线应改用波浪线**

局部剖视图：局部剖开，用波浪线分界

### 四、剖切面的种类

单一剖切面

几个平行的剖切平面（阶梯剖）

几个相交的剖切平面（旋转剖）

### 五、剖视图标注

剖切符号（粗短线表示剖切位置，箭头表示投影方向）+ 字母

### 六、注意事项

剖切面后的可见部分都要画出

虚线一般不画（除非表达需要）

## 【5.3 断面图】

### 一、断面图概念

仅画出剖切面与机件接触部分的图形

### 二、断面图与剖视图的区别

断面图：只画断面形状

剖视图：还要画断面后的结构

### 三、分类

移出断面：画在视图之外，轮廓用粗实线

重合断面：画在视图之内，轮廓用细实线

## 【5.4 规定画法和简化画法】

### 一、规定画法

肋板、轮辐在剖视图中不画剖面线

剖切平面沿纵向剖肋板时，肋板按不剖处理

### 二、简化画法

对称图形可只画一半或四分之一

相同结构可只画一个并标明数量

长零件可折断绘制

## 【5.5 局部放大图】

将机件的细小结构放大画出，用罗马数字标识（如Ⅰ、Ⅱ）

# 第六章 标准件和常用件

## 【6.1 螺纹及螺纹紧固件】

### 一、螺纹要素

牙型、公称直径（大径）、螺距、线数、旋向

### 二、螺纹分类

普通螺纹（M）：牙型角60°，用于连接

管螺纹（G、Rc）：牙型角55°，用于管件连接

梯形螺纹（Tr）：牙型角30°，用于传动

### 三、螺纹标记示例

M20×1.5-6H

（M：普通螺纹，20：大径，1.5：螺距，6H：公差带）

### 四、规定画法

外螺纹：大径用粗实线，小径用细实线（约0.85倍大径）

内螺纹（剖视）：大径用细实线，小径用粗实线

螺纹连接：旋合部分按外螺纹画

### 五、螺纹紧固件连接

螺栓连接、双头螺柱连接、螺钉连接

## 【6.2 键连接】

### 一、键的种类

平键、半圆键、楔键

### 二、标记示例

键 10×8×100 GB/T 1096-2003（宽×高×长）

### 三、画法要点

键的顶面与轮毂键槽底面：有间隙（画两条线）

侧面与轴槽、轮毂槽：紧密接触（画一条线）

## 【6.3 销连接】

### 一、销的种类

圆柱销、圆锥销

## 【6.4 齿轮】

### 一、圆柱齿轮基本参数

齿数z、模数m、压力角α（标准20°）

### 二、计算公式（重点记忆）

【分度圆直径】d = m × z

【齿顶圆直径】da = m(z+2)

【齿根圆直径】df = m(z-2.5）

齿距 p = πm

齿高 h = 2.25m

### 三、规定画法

齿顶圆：粗实线

分度圆：细点画线

齿根圆：细实线（或省略）

【记忆口诀】"齿顶圆粗，分度圆点画，齿根圆细实"

## 【6.5 弹簧】

### 一、圆柱螺旋压缩弹簧的规定画法

各圈用直线表示（近似画法）

有效圈数≥4圈时，每端只画1-2圈，中间用细点画线通过簧丝中心

弹簧两端并紧磨平

### 二、作图步骤

先画支承圈 → 再画有效圈 → 最后画弹簧轴线

# 第七章 零件图

## 【7.1 零件图的内容】

### 一、零件的分类

轴类、盘盖类、叉架类、箱体类

### 二、零件图的内容

一组视图、完整的尺寸、技术要求、标题栏

## 【7.2 零件图的视图选择和尺寸标注】

### 一、主视图选择原则

最能反映形状特征

符合工作位置或加工位置

### 二、各类零件的表达方法

轴类：主视图按加工位置（水平放置）

盘盖类：主视图轴线水平

箱体类：主视图反映工作位置，需多个视图

### 三、尺寸标注要点

标注设计基准或工艺基准

避免封闭尺寸链

便于测量和加工

## 【7.3 零件图上常见的工艺结构】

### 一、铸造工艺结构

拔模斜度、铸造圆角、加强筋

### 二、机械加工工艺结构

倒角（C×45°）、圆角

退刀槽、砂轮越程槽

中心孔

## 【7.4 零件图中的技术要求】

### 一、表面结构（粗糙度）

  **符号：基本符号（仅表示需加工）、去除材料符号（加一短横）、不去除材料符号（加圆圈）**。

参数：Ra（轮廓算术平均偏差），数值越小越光滑

示例：Ra 3.2表示较粗糙，Ra 0.8表示较光滑

### 二、极限与配合

配合种类：间隙配合、过盈配合、过渡配合

标注示例：φ30H7（孔）、φ30h6（轴）**大写=孔，小写=轴**

### 三、几何公差（形位公差）

形状公差：直线度、平面度、圆度、圆柱度

位置公差：平行度、垂直度、同轴度、对称度

跳动公差：圆跳动、全跳动

## 【7.5 读零件图】

读图步骤：

1. 看标题栏（名称、材料、比例）

2. 分析视图（主视图、其他视图）

3. 分析尺寸（基准、主要尺寸）

4. 分析技术要求（粗糙度、公差）

5. 综合想象立体形状

# 第八章 装配图

## 【8.1 装配图的作用和内容】

### 一、装配图的作用

表达机器或部件的装配关系、工作原理、技术要求

### 二、装配图的内容

一组视图、必要的尺寸、技术要求、零件编号、明细栏和标题栏

## 【8.2 装配图的表达方法】

### 一、规定画法

相邻零件的接触面或配合面只画一条线

相邻零件剖面线方向相反或间隔不同

紧固件、实心件（轴、球）沿纵向剖切时按不剖处理

### 二、特殊画法

假想画法：表示运动极限位置，用双点画线

拆卸画法：假想拆去某零件后画

夸大画法：薄片、间隙夸大画

## 【8.3 装配图的尺寸标注和技术要求】

### 一、装配图的尺寸类型

性能（规格）尺寸

装配尺寸（配合尺寸、相对位置尺寸）

安装尺寸

外形尺寸（总长、总宽、总高）

### 二、技术要求

装配要求、检验要求、使用要求等

用文字写在标题栏上方

## 【8.4 装配图的零件序号、明细栏和标题栏】

### 一、零件序号

序号用细实线引出，末端用圆点或箭头

序号按顺时针或逆时针方向排列

字高比尺寸数字大一倍

### 二、明细栏

填写序号、代号、名称、数量、材料、备注等

## 【8.5 装配工艺结构的合理性】

合理装配结构：

接触面转折处应有倒角或圆角

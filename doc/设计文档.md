# UniApp 复习资料应用设计文档

## 1. 产品定位

这是一个“静态复习资料阅读器”，不是在线课程平台。输入是结构化 JSON，输出是章节阅读、题目练习、搜索、收藏和进度。

第一阶段：无后端、无登录、无云数据库、无在线 AI，可完全离线。

## 2. MVP 功能

### 首页
资料列表：名称、科目、章节数、题目数、最近进度。

### 资料详情
章节目录与“继续学习”。

### 内容阅读
展示标题、正文、图片、表格和知识点；支持上一节/下一节。

### 题目练习
支持单选、多选、判断、填空/简答的基础展示。选择题提交后显示答案和解析。

### 搜索
搜索标题、正文、题干、选项和标签。

### 收藏与进度
本地保存收藏题目、已完成题目和阅读位置。

## 3. 页面

```text
pages/
  index/index.vue
  material/detail.vue
  material/read.vue
  practice/index.vue
  practice/question.vue
  search/index.vue
  favorites/index.vue
  settings/index.vue
```

底部导航建议：

```text
资料 | 练习 | 收藏 | 设置
```

## 4. 数据架构

```text
src/static/materials/index.json
        |
        +-- mechanical-drawing-basic.json
        +-- another-material.json
                    |
              materialStore
          /          |                 首页         阅读器       练习器
                    |
              localStorage
```

静态 JSON 只读；学习状态通过 `uni.setStorageSync` 保存。

## 5. 学习状态

```ts
interface StudyState {
  materialId: string
  completedSections: string[]
  completedQuestions: string[]
  favoriteQuestions: string[]
  lastSectionId?: string
  lastQuestionId?: string
  updatedAt: string
}
```

Storage：

```text
review:state:{materialId}
```

不要把状态写回资料 JSON。

## 6. UI 原则

- 手机优先、单列布局；
- 正文可读性优先；
- 默认正文约 16px；
- 标题层级明显；
- 答案/解析明显区分；
- 操作按钮易点击；
- 少动画；
- 深色模式可后置。

## 7. 阅读体验

顶部显示章节和进度：

```text
第一章 制图基本知识
3 / 8 章节
```

底部：

```text
上一节    标记已复习    下一节
```

长章节连续滚动；图片点击放大。

## 8. 练习体验

```text
第 12 题 / 80

题干

○ A ...
○ B ...
○ C ...
○ D ...

[提交答案]

答案：B
解析：...
```

提交前不显示答案，提交后显示结果和解析。

## 9. 搜索

资料规模不大时直接内存字符串匹配即可。搜索字段：

- section.title
- block.text
- question.stem
- question.options
- question.tags

后续规模变大再做倒排索引。

## 10. 性能

第一版点击资料后才加载对应 JSON。

单份资料超过约 2–5 MB 时，再按章节拆分：

```text
materials/mechanical-drawing-basic/index.json
materials/mechanical-drawing-basic/section-001.json
```

不要提前复杂化。

## 11. 技术选型

- UniApp + Vue 3；
- TypeScript；
- Vite；
- Pinia 可选；
- uni.setStorageSync / uni.getStorageSync；
- 不强依赖大型 UI 组件库。

## 12. 非目标

第一版不做：

- 用户账号；
- 云同步；
- 在线后台；
- 在线编辑；
- DOCX 在线解析；
- 在线 AI；
- 社交；
- 支付；
- 运营后台。

## 13. 验收

完全断网时仍能：

1. 查看资料；
2. 打开机械制图资料；
3. 浏览章节；
4. 查看文字、图片、表格；
5. 做题并看解析；
6. 搜索；
7. 收藏；
8. 恢复学习进度。

目标是一个可靠的本地复习资料阅读器，而不是缩水的在线教育平台。

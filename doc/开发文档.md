# UniApp 复习资料应用开发文档

## 1. 工程结构

建议：

```text
ReviewMaterials/
├─ materials-source/
├─ scripts/
│  └─ materials/
│     ├─ convert_docx.py
│     └─ validate_materials.py
├─ src/
│  ├─ pages/
│  ├─ components/
│  ├─ composables/
│  ├─ stores/
│  ├─ types/
│  └─ static/
│     └─ materials/
├─ App.vue
├─ pages.json
├─ manifest.json
├─ package.json
└─ tsconfig.json
```

如果首期只开发 App，也可以先建立 UniApp 工程，再补充转换脚本。

## 2. 类型定义

建立 `src/types/material.ts`：

```ts
export type QuestionType =
  | 'single_choice'
  | 'multiple_choice'
  | 'true_false'
  | 'fill_blank'
  | 'short_answer'
  | 'calculation'
  | 'unknown'

export interface MaterialIndexItem {
  id: string
  title: string
  subject?: string
  file: string
  questionCount: number
  sectionCount: number
  updatedAt?: string
}

export interface MaterialIndex {
  schemaVersion: number
  materials: MaterialIndexItem[]
}

export interface MaterialSection {
  id: string
  title: string
  level: number
  parentId: string | null
  blockIds: string[]
}

export interface MaterialQuestion {
  id: string
  sectionId?: string
  type: QuestionType
  stem: string
  options?: { key: string; text: string }[]
  answer?: string[]
  analysis?: string
  tags?: string[]
}

export interface Material {
  schemaVersion: number
  id: string
  title: string
  subject?: string
  sections: MaterialSection[]
  questions: MaterialQuestion[]
  blocks: unknown[]
}
```

## 3. 数据加载

建立 `src/composables/useMaterials.ts`：

- `loadMaterialIndex()`：读取 index.json；
- `loadMaterial(id)`：根据 index 找 JSON；
- 缓存当前 material，避免重复读取。

静态 JSON 用 import 优先，保证各端兼容；如果资料数量较多，可以建立生成的 manifest 模块。

## 4. 状态管理

建立：

```text
src/stores/study.ts
```

负责：

- 当前资料；
- 当前章节；
- 当前题目；
- 完成状态；
- 收藏状态；
- 最近位置。

持久化只写 Storage。

## 5. 组件

建议组件：

```text
MaterialCard.vue
SectionTree.vue
ContentBlock.vue
QuestionCard.vue
AnswerPanel.vue
ProgressBar.vue
EmptyState.vue
```

`ContentBlock` 根据 `block.type` 渲染：

```text
heading -> 标题
paragraph -> rich-text/文本
image -> image
table -> table
list_item -> 列表
```

## 6. 路由参数

资料：

```text
/material/detail?id=mechanical-drawing-basic
```

阅读：

```text
/material/read?materialId=xxx&sectionId=xxx
```

题目：

```text
/practice/question?materialId=xxx&questionId=xxx
```

不要把完整 JSON 放进 URL。

## 7. 搜索实现

MVP：

```ts
const keyword = query.trim().toLowerCase()
```

对标题、正文、题干、选项和 tags 做 `includes`。

搜索结果统一：

```ts
interface SearchResult {
  type: 'section' | 'block' | 'question'
  materialId: string
  sectionId?: string
  questionId?: string
  title: string
  snippet: string
}
```

## 8. 收藏与进度

所有状态写入：

```text
review:state:{materialId}
```

写入时使用完整对象覆盖，避免产生多个版本的状态 key。

## 9. 题目答题

状态：

```text
unanswered
answered_correct
answered_wrong
```

提交前隐藏答案；提交后比较标准答案。

多选题比较时先排序再比较。

填空和简答第一版只展示参考答案，不做复杂自动评分。

## 10. 资源规范

所有资料 JSON UTF-8。

图片使用相对路径，例如：

```text
assets/mechanical-drawing-basic/image-001.png
```

不在 JSON 中保存 base64。

## 11. 开发命令

```bash
npm install
npm run dev:h5
npm run build:h5
```

具体命令以实际 UniApp CLI 工程模板为准。

转换：

```bash
python scripts/materials/convert_docx.py ...
python scripts/materials/validate_materials.py src/static/materials
```

## 12. 测试

至少覆盖：

- index.json 加载；
- material JSON 加载；
- 空资料处理；
- section 导航；
- 图片加载；
- 搜索；
- 收藏持久化；
- 阅读进度持久化；
- 单选/多选/判断提交；
- JSON 校验失败时的错误提示。

## 13. 代码原则

- TypeScript 优先；
- 页面只负责组合，不承载大量数据处理；
- 数据解析与 UI 解耦；
- 不在页面中硬编码资料内容；
- 所有静态资料通过统一 loader 获取；
- 组件保持小而明确；
- 不为未来功能提前引入大型依赖。

## 14. 错误处理

如果 JSON 加载失败：

```text
资料加载失败
请检查资料资源是否完整。
[返回资料列表]
```

如果某张图片加载失败，不应让整页崩溃。

## 15. Definition of Done

一个功能只有同时满足：

- 类型检查通过；
- 页面可运行；
- Android/H5 至少验证一种；
- 断网验证；
- 数据来自静态资源；
- 状态重启后可恢复；
- 无控制台严重错误；

才算完成。
